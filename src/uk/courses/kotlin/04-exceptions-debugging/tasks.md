# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

## Варіанти

### Варіант 1. Калькулятор {#v1}

**1. Початковий рівень.** Створити консольну програму Kotlin: читати рядок a op b, a/b скінченні від −1000 до 1000, op лише +,-,\*,/; вивести результат, ділення на 0 відхилити. Оформити предметну функцію з явним контрактом, обробити очікувані винятки окремо від вводу та не друкувати успіх після помилки.

**2. Базовий рівень.** Створити консольну програму Kotlin: читати рядок a op b, a/b скінченні від −1000 до 1000, op лише +,-,\*,/; вивести результат, ділення на 0 відхилити. Описати предметну помилку власним типом, зберегти cause під час обгортання; перевірити нормальний, граничний і неправильний ввід та незмінність стану після збою.

**3. Високий рівень.** Створити консольну програму Kotlin: читати рядок a op b, a/b скінченні від −1000 до 1000, op лише +,-,\*,/; вивести результат, ділення на 0 відхилити. Повернути результат предметної операції як Result і явно обробити через fold; не перехоплювати всю програму одним catch Throwable. Для CLI помилка дає stderr і код 2, успіх – код 0. Додати не менше п’яти перевірок, відтворити один збій у налагоджувачі й пояснити стек та стан. Додати аргументи CLI у форматі ключ=значення та `--help`; без аргументів читати ті самі поля з клавіатури. Виводити підписаний табличний звіт із підсумком; помилки надсилати у stderr. Коди завершення: 0 – успіх або довідка, 2 – неправильний ввід, 1 – операційний збій.
