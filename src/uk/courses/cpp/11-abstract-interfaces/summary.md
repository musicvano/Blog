# Підсумки

## Висновки

Інтерфейс описує потрібну клієнтові можливість. Композиція поєднує контекст зі змінним алгоритмом. Спільна віртуальна база усуває дублювання стану ромба. Час життя невласних зв’язків є частиною контракту.
