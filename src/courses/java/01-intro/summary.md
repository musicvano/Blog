# Summary

## Conclusions

The JDK provides tools, the JVM executes bytecode, and the IDE organizes editing and execution. Reproducible work includes source files, a clear run command, a reference result, and a history of meaningful changes.

## Self-check questions

1. How does the Java language differ from the Java platform?
2. Why do you need javac when java exists?
3. What does bytecode portability mean?
4. Why does JAVA\_HOME not end with bin?
5. How does running a class differ from running a source file?
6. Which arguments are passed to the args array?
7. Why does a compact file still have an implicit class?
8. How do Program arguments differ from VM options?
9. Which state of a file does Git commit after git add?
10. Why does successful compilation not prove that a formula is correct?
