# Типові помилки

## Типові помилки

У табл. 14.2 наведено помилки, які найчастіше трапляються під час створення анімацій і мультимедійних застосунків.

Таблиця 14.2. Типові помилки під час анімації та роботи з мультимедіа {.caption}

| **Проблема** | **Причина** | **Виправлення** |
| --- | --- | --- |
| анімація не компілюється або не діє | анімується звичайна властивість C# чи поле | анімувати властивість залежності; для власного класу зареєструвати її |
| анімація повороту чи масштабу не має ефекту | `RenderTransform` не задано (там незмінне тотожне перетворення) або шлях з помилкою | задати `<RotateTransform/>` заздалегідь, перевірити `(UIElement.RenderTransform).(…)` |
| після анімації присвоєння властивості в коді ігнорується | `FillBehavior="HoldEnd"` утримує значення | `BeginAnimation(property, null)` або `FillBehavior="Stop"` і `Completed` |
| *Cannot animate … because the object is sealed or frozen* | пензель чи перетворення заморожене (зі стилю, `Brushes.Gray`) | призначити нову копію `new SolidColorBrush(…)` або `Clone()` |
| `Pause`/`Stop` не діють на розкадрування | запущено без `isControllable: true` або для іншого елемента | `Begin(this, true)` і той самий елемент у всіх викликах |
| кнопки плеєра не працюють | `LoadedBehavior` має значення `Play` за замовчуванням | `LoadedBehavior="Manual"` |
| медіафайл не знайдено після збирання, `MediaFailed` | файл не копіюється або шлях відносний | *Content*, *Copy if newer*, шлях від `AppContext.BaseDirectory` |
| інтерфейс «гальмує» | десятки анімацій `Width`/`Margin`, `LayoutTransform` | анімувати `RenderTransform`, `Opacity`, `BitmapCache`, `Freeze` |
