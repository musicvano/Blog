# Корисні посилання

## Документація та специфікація

- [C# documentation](https://learn.microsoft.com/en-us/dotnet/csharp/) — офіційна документація мови C# з посібниками та довідником
- [C# language specification](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/language-specification/) — формальний опис синтаксису та семантики мови C#
- [What's new in C# 14](https://learn.microsoft.com/en-us/dotnet/csharp/whats-new/csharp-14) — нові можливості версії мови, що входить до .NET 10
- [.NET documentation](https://learn.microsoft.com/en-us/dotnet/) — документація платформи .NET, середовища виконання та інструментів
- [.NET API browser](https://learn.microsoft.com/en-us/dotnet/api/) — пошук класів і методів бібліотеки .NET з прикладами
- [C# coding conventions](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions) — рекомендований стиль іменування та оформлення коду C#

## Посібники за темами курсу

- [A tour of the C# language](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/) — стислий огляд типів, класів, узагальнень та інших можливостей мови
- [Object-Oriented programming (C#)](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/tutorials/oop) — інкапсуляція, наслідування та поліморфізм на прикладах C#
- [Collections and data structures](https://learn.microsoft.com/en-us/dotnet/standard/collections/) — вибір узагальнених колекцій List, Dictionary, HashSet та інших
- [Language Integrated Query (LINQ)](https://learn.microsoft.com/en-us/dotnet/csharp/linq/) — запити до колекцій і даних засобами LINQ
- [JSON serialization in .NET](https://learn.microsoft.com/en-us/dotnet/standard/serialization/system-text-json/overview) — серіалізація об’єктів у JSON і назад за допомогою System.Text.Json
- [Unit testing in .NET](https://learn.microsoft.com/en-us/dotnet/core/testing/) — написання та запуск модульних тестів із MSTest, xUnit і NUnit

## Середовище та інструменти

- [Visual Studio documentation](https://learn.microsoft.com/en-us/visualstudio/windows/) — робота в Visual Studio — проєкти, редактор, збирання
- [Debug C# code using Visual Studio](https://learn.microsoft.com/en-us/visualstudio/get-started/csharp/tutorial-debugger) — покрокове налагодження C#-програм із точками зупинки
- [Git Reference Manual](https://git-scm.com/docs) — офіційний довідник команд системи керування версіями Git
- [SharpLab](https://sharplab.io) — онлайн-запуск коду C# з переглядом IL і розгорнутого коду

## Практика, патерни та спільнота

- [Exercism C# Track](https://exercism.org/tracks/csharp) — задачі з автоматичною перевіркою та рецензіями менторів
- [Refactoring.Guru — Design Patterns in C#](https://refactoring.guru/design-patterns/csharp) — ілюстровані пояснення патернів проєктування з прикладами на C#
- [.NET Blog](https://devblogs.microsoft.com/dotnet/) — офіційні новини та статті команди .NET
- [.NET YouTube channel](https://www.youtube.com/@dotnet) — відеоуроки, доповіді .NET Conf і трансляції від Microsoft
