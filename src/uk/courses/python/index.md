# Об’єктно-орієнтоване програмування Python

Python – одна з найпопулярніших мов програмування й основний інструмент автоматизації, аналізу даних, машинного навчання та веброзробки. Простий синтаксис дозволяє швидко перейти від ідеї до робочої програми, а курс дає міцну основу об’єктно-орієнтованого програмування, потрібну для подальшого опанування цих напрямів.

Курс присвячено вивченню мови програмування Python 3.14 у середовищі JetBrains PyCharm – від базових конструкцій мови, вбудованих колекцій і функціонального програмування до об’єктно-орієнтованого програмування, роботи з файлами та модульного тестування. На завершальному етапі здобувачі навчаються працювати з реляційними базами даних за допомогою sqlite3 і SQLAlchemy, виконувати числові обчислення й аналіз даних засобами NumPy та pandas, будувати графіки з Matplotlib, створювати графічні застосунки на PySide6, пакувати застосунки та застосовувати статичний аналіз коду. Кожна тема курсу поєднує лекцію з лабораторною роботою.
