# Тема 13. Побудова обчислювального кластера на Linux з планувальником завдань Slurm; налаштування високопродуктивних обчислень

**Мета:** ознайомитися з архітектурою обчислювального кластера та компонентами планувальника Slurm; навчитися готувати вузли Ubuntu Server (мережа, користувачі, SSH, NFS, синхронізація часу), встановлювати й налаштовувати Slurm з автентифікацією MUNGE, писати скрипти пакетних завдань для послідовних, MPI- і гібридних програм, масивів і ланцюжків залежних завдань; опанувати діагностику вузлів, облік завдань командою sacct і налаштування операційної системи для високопродуктивних обчислень.
