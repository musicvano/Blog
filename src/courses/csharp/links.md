# Useful links

## Documentation and specification

- [C# documentation](https://learn.microsoft.com/en-us/dotnet/csharp/) — official C# documentation with guides and a reference
- [C# language specification](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/language-specification/) — a formal description of C# syntax and semantics
- [What's new in C# 14](https://learn.microsoft.com/en-us/dotnet/csharp/whats-new/csharp-14) — new features in the language version included with .NET 10
- [.NET documentation](https://learn.microsoft.com/en-us/dotnet/) — documentation for the .NET platform, runtime, and tools
- [.NET API browser](https://learn.microsoft.com/en-us/dotnet/api/) — search .NET library classes and methods with examples
- [C# coding conventions](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions) — recommended C# naming and code formatting conventions

## Guides by course topic

- [A tour of the C# language](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/) — a brief overview of types, classes, generics, and other language features
- [Object-Oriented programming (C#)](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/tutorials/oop) — encapsulation, inheritance, and polymorphism through C# examples
- [Collections and data structures](https://learn.microsoft.com/en-us/dotnet/standard/collections/) — choosing generic collections such as List, Dictionary, and HashSet
- [Language Integrated Query (LINQ)](https://learn.microsoft.com/en-us/dotnet/csharp/linq/) — querying collections and data with LINQ
- [JSON serialization in .NET](https://learn.microsoft.com/en-us/dotnet/standard/serialization/system-text-json/overview) — serializing objects to JSON and back with System.Text.Json
- [Unit testing in .NET](https://learn.microsoft.com/en-us/dotnet/core/testing/) — writing and running unit tests with MSTest, xUnit, and NUnit

## Environment and tools

- [Visual Studio documentation](https://learn.microsoft.com/en-us/visualstudio/windows/) — working in Visual Studio: projects, the editor, and builds
- [Debug C# code using Visual Studio](https://learn.microsoft.com/en-us/visualstudio/get-started/csharp/tutorial-debugger) — step-by-step debugging of C# programs with breakpoints
- [Git Reference Manual](https://git-scm.com/docs) — official command reference for the Git version control system
- [SharpLab](https://sharplab.io) — run C# code online and view IL and expanded code
