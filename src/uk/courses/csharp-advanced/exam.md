# Контрольні завдання

Практичні завдання за темами курсу для перевірки знань. Кожне завдання — окрема програма.

## Тема 1. Керування версіями Git

1. Створити консольну програму C# «Конвертер температур» (Цельсій, Фаренгейт, Кельвін) у новому репозиторії Git з файлами `.gitignore` і `.gitattributes`, створеними шаблонами `dotnet new`; зафіксувати розробку щонайменше чотирма комітами зі змістовними повідомленнями, показати `git status`, `git log --oneline` і зміни останнього коміту командою `git show --stat`.
2. Створити консольну програму C# «Облік завдань» (завдання з пріоритетом і терміном) у репозиторії Git, створити гілки `feature/priority` і `feature/deadline`, зробити в кожній по коміту, злити першу гілку перемотуванням, а другу – тристороннім злиттям після нового коміту в `main`; видалити злиті гілки й показати `git log --oneline --graph --all`.
3. Створити консольну програму C# «Телефонний довідник» (імена й номери телефонів) у репозиторії Git, змінити той самий рядок виведення в гілці `feature/format` і в `main`, злити гілку, розв’язати конфлікт злиття (у терміналі або у Visual Studio 2026), перевірити збірку й завершити злиття; показати маркери конфлікту, `git status` під час конфлікту та граф історії після злиття.
4. Створити консольну програму C# «Каса кінотеатру» (сеанси та продаж квитків) у репозиторії Git і зробити два помилкові коміти: перший скасувати командою `git revert`, другий прибрати командою `git reset --hard HEAD~1`, а потім відновити його за допомогою `git reflog`; показати `git log --oneline` після кожної дії й пояснити, коли допустимо використовувати `git reset`.
5. Створити консольну програму C# «Облік відвідувань» (студенти та відвідані заняття) у репозиторії Git, почати зміну в гілці `feature/report`, сховати незавершену роботу командою `git stash push -m`, перейти на `main`, виправити й закомітити помилку, повернутися в гілку, відновити схованку і завершити зміну комітом; показати `git stash list` і `git log --oneline --graph --all`.
6. Створити консольну програму C# «Калькулятор індексу маси тіла» (зріст, вага, ІМТ) у репозиторії Git і позначити дві її версії анотованими тегами `v1.0.0` і `v1.1.0` з описом змін і файлом `CHANGELOG.md`; показати `git tag -n`, `git diff --stat v1.0.0 v1.1.0`, вміст `Program.cs` у версії 1.0.0 (`git show v1.0.0:Program.cs`) і тимчасово перейти до неї командою `git switch --detach`.
7. Створити консольну програму C# «Облік складу» (товари та залишки) у репозиторії Git, зробити в гілці `experiment/import` три коміти, один з яких виправляє помилку, що є і в `main`; перенести в `main` лише це виправлення командою `git cherry-pick`, перебазувати гілку на `main` і показати, що Git пропустив перенесений коміт.
8. Створити консольну програму C# «Розклад іспитів» (дисципліна, дата, аудиторія), порожній репозиторій `D:\Labs\remote\Exams.git` і два клони від імені двох учасників; обидва роблять коміти, другий отримує відмову `git push`, виконує `git pull`, за потреби розв’язує конфлікт і надсилає зміни; показати `git log --oneline --graph` в обох клонах і `git remote -v`.
9. Створити консольну програму C# «Конвертер валют» (сума та курс обміну) у репозиторії Git з історією не менше ніж із шести комітів, в одному з яких внесено помилку в обчислення; знайти цей коміт командою `git bisect`, переглянути його командами `git show` і `git blame`, скасувати помилку командою `git revert` і показати `git log --oneline`.
10. Створити консольну програму C# «Облік бюджету» (доходи та витрати) у репозиторії Git і хук `pre-commit` у папці `.githooks`, який виконує `dotnet build` і скасовує коміт, якщо збірка не вдалася; підключити папку командою `git config core.hooksPath .githooks`, показати відмову коміту з помилкою компіляції та успішний коміт після виправлення.

## Тема 2. Регулярні вирази

11. Створити консольну програму, яка запитує в користувача поштовий індекс (п’ять цифр), номер телефону `+380XXXXXXXXX` і дату `дд.мм.рррр`, перевіряє кожне значення методом `Regex.IsMatch` з якорями `^` і `\z`, для дати додатково перевіряє її існування методом `DateOnly.TryParseExact` та виводить для кожного поля «правильно» або опис очікуваного формату.
12. Створити консольну програму, яка запитує в користувача текст і слово, знаходить усі входження слова як цілого слова без урахування регістру (межі `\b`, `Regex.Escape`) та виводить кількість збігів і позицію кожного з них.
13. Створити консольну програму, яка запитує рядки `Прізвище Ім’я, КН-21, 87` до введення порожнього рядка, розбирає їх шаблоном з іменованими групами (прізвище, ім’я, група, бал від 0 до 100), відхиляє неправильні рядки з повідомленням і виводить таблицю студентів та середній бал кожної групи.
14. Створити консольну програму, яка читає текст із файлу, замінює дати `рррр-мм-дд` на `дд.мм.рррр` підстановкою груп, а ціни в доларах `$12.50` на ціни в гривнях за курсом, введеним користувачем, методом `Replace` з `MatchEvaluator`, та виводить результат і кількість замін кожного виду.
15. Створити консольну програму, яка запитує рядок чисел, розділених комами, крапками з комою, пробілами або табуляціями в будь-якій кількості, розбиває його методом `Regex.Split`, перевіряє кожне число методом `TryParse` і виводить суму, середнє значення та некоректні елементи.
16. Створити консольну програму, яка запитує пароль, перевіряє його одним шаблоном із переглядами вперед (щонайменше 10 символів, велика й мала літери, цифра, без пробілів), а якщо перевірка не пройдена, окремими шаблонами визначає та виводить усі порушені правила.
17. Створити консольну програму, яка читає текстовий файл із кінцями рядків Windows, у режимі `RegexOptions.Multiline` знаходить рядки, що починаються словами `HACK` або `FIXME` без урахування регістру, та виводить номер кожного рядка і текст після ключового слова без символу `\r`.
18. Створити консольну програму зі статичним `partial`-класом, у якому атрибутом `[GeneratedRegex]` оголошено шаблони адреси e-mail, українського IBAN і поштового індексу; програма читає значення з файлу (одне в рядку) та виводить таблицю «значення – тип – формат правильний».
19. Створити консольну програму, яка запитує кількість символів *n*, будує рядок з *n* літер `a` і символу `!`, перевіряє його шаблоном `^(a+)+$` з тайм-аутом 200 мс, перехоплює `RegexMatchTimeoutException`, а потім перевіряє той самий рядок з параметром `RegexOptions.NonBacktracking` і рівносильним шаблоном `^a+$`, виводячи час кожної перевірки.
20. Створити консольну програму, яка читає файл журналу застосунку з рядками `2026-09-17 10:15:32 [ERROR] текст`, підраховує записи за рівнями (`INFO`, `WARN`, `ERROR`), замінює числа в текстах помилок на `N` для групування однакових повідомлень і виводить п’ять найчастіших повідомлень про помилки з кількістю.

## Тема 3. Основи Windows Forms

21. Створити застосунок Windows Forms, у якому користувач вводить у текстові поля довжини трьох сторін трикутника, а після натискання кнопки *Calculate* бачить периметр, площу за формулою Герона та вид трикутника. Некоректні значення (не числа, недодатні числа, сторони, що не утворюють трикутник) позначаються компонентом `ErrorProvider`.
22. Створити застосунок Windows Forms «Реєстрація користувача» з полями логіна (3–20 латинських літер і цифр), електронної пошти, пароля та підтвердження пароля. Поля перевіряються в подіях `Validating` з `ErrorProvider`, кнопка *Cancel* закриває форму без перевірки, а кнопка *Register* показує `MessageBox` лише за коректних даних.
23. Створити застосунок Windows Forms для замовлення кави з вибором напою (`RadioButton`), розміру (`ComboBox`), додатків (`CheckBox`) і кількості (`NumericUpDown`). Вартість оновлюється після кожної зміни одним спільним обробником подій, а кнопка *Order* показує підсумок замовлення в `MessageBox`.
24. Створити застосунок Windows Forms зі списком міст у `ListBox` і полем введення назви міста з кнопками *Add*, *Remove* і *Sort*. Порожні назви й дублікати не додаються (повідомлення в `MessageBox`), кнопка *Remove* доступна лише тоді, коли місто виділено, а напис показує кількість міст.
25. Створити застосунок Windows Forms «Анкета» з написами й полями, розміщеними в `TableLayoutPanel`, і кнопками *OK* і *Cancel*, прив’язаними до правого нижнього кута форми (`Anchor`). Під час зміни розміру вікна поля розтягуються, форма має мінімальний розмір, а клавіші **Enter** і **Esc** натискають відповідні кнопки.
26. Створити застосунок Windows Forms «Нотатник» з головним меню *File* (*New*, *Open…*, *Save As…*, *Exit*) з клавішами швидкого доступу, багаторядковим полем тексту на всю форму і рядком стану з кількістю символів. Файли відкриваються й зберігаються через `OpenFileDialog` і `SaveFileDialog`, а помилки читання й запису показуються в `MessageBox`.
27. Створити застосунок Windows Forms «Таймер зворотного відліку», у якому користувач задає хвилини й секунди в `NumericUpDown`, запускає, призупиняє й скидає відлік кнопками. Компонент `Timer` оновлює напис щосекунди, а після завершення відліку форма змінює колір тла й показує `MessageBox`.
28. Створити застосунок Windows Forms з головною формою зі списком товарів і модальною формою додавання товару (назва, ціна, кількість) з кнопками *OK* і *Cancel*. Модальна форма перевіряє поля й закривається з `DialogResult.OK` лише за коректних даних; головна форма додає товар і показує загальну вартість.
29. Створити застосунок Windows Forms «Облік студентів» з таблицею `DataGridView`, прив’язаною до `BindingList<T>` через `BindingSource`, і полями прізвища, групи та середнього балу (60–100) з кнопками *Add* і *Delete*. Рядок стану показує кількість студентів і середній бал групи.
30. Створити застосунок Windows Forms, який під час руху миші над панеллю показує координати курсора в рядку стану, після клацання лівою кнопкою додає точку «X, Y» у `ListBox`, після натискання **Ctrl+Z** (подія `KeyDown` форми з `KeyPreview`) видаляє останню точку, а контекстне меню списку містить команди *Copy* (копіювати точки в буфер обміну) і *Clear*.

## Тема 4. Графіка GDI+

31. Створити застосунок Windows Forms, який у методі `OnPaint` малює будиночок із прямокутника, трикутного даху (`FillPolygon`), вікон зі штриховкою та сонця-кола; малюнок масштабується під розмір вікна і не зникає після згортання вікна.
32. Створити застосунок Windows Forms, який малює три прямокутники, заповнені пензлями `SolidBrush`, `HatchBrush` і `LinearGradientBrush`, з підписами назв пензлів, вирівняними по центру прямокутників; тип штриховки вибирається в `ComboBox`.
33. Створити застосунок Windows Forms, у якому текст, введений у поле, виводиться в рамці по центру вікна; розмір шрифту автоматично підбирається через `MeasureString` так, щоб текст займав не більше 80 % ширини вікна.
34. Створити застосунок Windows Forms, який будує графік функції *y* = $x^{2}$ − 4 на відрізку, заданому користувачем (початок менший за кінець), з осями, поділками й підписами; математичні координати перетворюються на пікселі за допомогою класу `Matrix`.
35. Створити застосунок Windows Forms, який створює `Bitmap` 400 × 300, малює в ньому таблицю множення 5 × 5 з рамками і зберігає зображення у PNG-файл, вибраний у `SaveFileDialog`; зображення показується у `PictureBox`.
36. Створити застосунок Windows Forms, який відкриває зображення і перетворює його на негатив методами `GetPixel` і `SetPixel`, показуючи оригінал і результат; про некоректний файл повідомляється без аварійного завершення програми.
37. Створити застосунок Windows Forms, у якому користувач малює мишею прямокутники (натиснути, протягнути, відпустити), усі прямокутники зберігаються в списку, а правий клік видаляє прямокутник під курсором.
38. Створити застосунок Windows Forms, у якому м’яч-коло рухається й відбивається від країв вікна за `Timer`, швидкість змінюється клавішами «+» і «−», а анімація не мерехтить завдяки подвійній буферизації.
39. Створити власний елемент керування `BatteryIndicator` з властивістю `Level` (0–100) з атрибутами `Category`, `Description` і `DefaultValue`, який малює батарейку з сегментами заряду, та форму, на якій рівень змінюється `TrackBar`.
40. Створити застосунок Windows Forms, який малює п’ять фігур (коло, квадрат, трикутник, зірка, еліпс) як об’єкти `GraphicsPath` і після клацання мишею виводить у рядку стану назву фігури під курсором (перевірка `IsVisible`).

## Тема 5. Асинхронність async/await

41. Створити застосунок Windows Forms, який після натискання кнопки підраховує в `Task.Run` кількість простих чисел до введеного числа (не більше 50 000 000). Під час обчислення кнопка вимкнена, курсор має вигляд очікування, а результат і час виводяться в напис.
42. Створити застосунок Windows Forms «Нотатки», який асинхронно відкриває та зберігає текстові файли (`File.ReadAllTextAsync`, `File.WriteAllTextAsync`) через стандартні діалоги й показує помилки читання та запису в `MessageBox`, не блокуючи інтерфейс.
43. Створити застосунок Windows Forms, який імітує тривалу операцію з десяти кроків (`Task.Delay` 500 мс кожен) з перебігом у `ProgressBar` через `IProgress<int>` і кнопкою *Cancel*; після скасування напис показує номер кроку, на якому операцію зупинено.
44. Створити застосунок Windows Forms, який асинхронно копіює вибраний файл у вибрану папку порціями по 1 МБ з перебігом у відсотках і кнопкою *Cancel*; після скасування частково скопійований файл видаляється.
45. Створити застосунок Windows Forms, який запускає п’ять імітованих завантажень різної тривалості одночасно, показує час завершення кожного в списку (`Task.WhenAll`) і назву найшвидшого (`Task.WhenAny`).
46. Створити застосунок Windows Forms, який виконує імітовану операцію випадкової тривалості від 1 до 5 с із тайм-аутом, заданим у `NumericUpDown`; якщо операцію не завершено вчасно, вона скасовується, а напис показує «Timeout».
47. Створити застосунок Windows Forms, який обробляє 20 імітованих задач (`Task.Delay` випадкової тривалості), виконуючи одночасно не більше заданої кількості (`SemaphoreSlim`), і показує в написі поточну та максимальну кількість задач, що виконуються одночасно.
48. Створити застосунок Windows Forms, який асинхронно обробляє кілька вибраних текстових файлів одночасно (підрахунок слів); якщо деякі файли не вдалося прочитати, застосунок показує результати успішних файлів і список усіх помилок (`Task.WhenAll`, `Exception.InnerExceptions`).
49. Створити застосунок Windows Forms, який асинхронно читає великий текстовий файл рядок за рядком через метод, що повертає `IAsyncEnumerable<string>`, і додає в `ListBox` рядки, що містять введене слово, одразу після знаходження, з можливістю скасування.
