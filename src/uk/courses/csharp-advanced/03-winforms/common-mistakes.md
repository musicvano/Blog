# Типові помилки

## Типові помилки

У табл. 3.5 наведено помилки, яких найчастіше припускаються початківці під час створення застосунків Windows Forms.

Таблиця 3.5. Типові помилки в застосунках Windows Forms {.caption}

| **Проблема** | **Причина** | **Виправлення** |
| --- | --- | --- |
| код обробників `button1_Click`, `textBox3_TextChanged` важко читати | елементи не перейменовано | змінювати `(Name)` одразу після розміщення: `convertButton` |
| помилка компіляції після видалення методу-обробника | у `Designer.cs` залишилася підписка на подію | очистити подію у вікні *Properties* (*Reset*) |
| `FormatException` в обробнику кнопки | `double.Parse` з тексту поля без перевірки | `TryParse`, `NumericUpDown`, `ErrorProvider` |
| вікно «зависає» під час обчислень | тривала операція в обробнику блокує цикл повідомлень | асинхронний код `async`/`await` (тема 5) |
| елемент із `Dock = Fill` перекриває меню або рядок стану | неправильний порядок елементів (*Z-order*) | *Bring to Front* для елемента з `Fill` |
| кнопка *Cancel* не закриває форму з некоректним полем | `Validating` з `e.Cancel = true` не відпускає фокус | `CausesValidation = false` для кнопки *Cancel* |
