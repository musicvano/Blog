# Підсумки

## Висновки

Records описують значення через компоненти, enum задає скінченні константи, sealed обмежує альтернативи, а зразки дозволяють безпечно розібрати їхню структуру. Компактний синтаксис не скасовує інваріантів, захисних копій і перевірки числових меж.
