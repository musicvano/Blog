# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Для всіх рівнів потрібна UML-діаграма з напрямками узагальнення й реалізації інтерфейсів. Клієнтський алгоритм обробляє спільний тип і не розгалужується за назвами конкретних класів, якщо цього не вимагає саме введення даних. У високому рівні додайте `--help`, повторюваний `--item` з описом полів, клавіатурний режим без аргументів, stderr і код 2 для помилок, код 0 для успіху. Подайте вирівняний звіт та підсумок. Усі тарифи, податки й повідомлення є заданими навчальними моделями; зовнішні сервіси не викликаються.
