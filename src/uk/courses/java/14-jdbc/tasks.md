# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

## Варіанти

### Варіант 1. Бібліотека {#v1}

**1. Початковий рівень.** Створити самостійну консольну Java/JDBC-програму «Бібліотека» з PostgreSQL: книги, читачі, видачі, DAO і транзакції. Для основної сутності визначити id, назву й одну предметну характеристику. Через меню додавати, переглядати, редагувати та видаляти записи за id; неправильне введення й відсутній id повідомляти явно. Застосувати PreparedStatement і try-with-resources, показати збереження після повторного запуску. Поля книги: назва, автор, доступність; видача читачу робить книгу недоступною. Звіт: число видач кожного читача, повторну видачу заборонити.

**2. Базовий рівень.** Створити самостійну консольну Java/JDBC-програму «Бібліотека» з PostgreSQL: книги, читачі, видачі, DAO і транзакції. Описати три пов’язані таблиці з ключами й обмеженнями, реалізувати DAO та меню введення операцій. Вивести звіт JOIN із групуванням, кількістю або точною сумою за основною сутністю; включити порожні групи, задати порядок. Перевірити дублікати, зовнішні ключі та SQL-подібний текст як звичайне значення. Поля книги: назва, автор, доступність; видача читачу робить книгу недоступною. Звіт: число видач кожного читача, повторну видачу заборонити.

**3. Високий рівень.** Створити самостійну Java/JDBC-програму «Бібліотека» на PostgreSQL: книги, читачі, видачі, DAO і транзакції. Виділити DAO й сервіс транзакційної операції, яка змінює щонайменше дві таблиці; перевірити предметний інваріант і конкурентний конфлікт. Приймати `--config=path`, `--action=add|list|report`, `--record=field:value,...`, `--help`; без аргументів надати меню. Вивести вирівняний звіт із підсумками, помилки до stderr, коди 0/2/1. Додати JUnit-тести відкату після першої зміни, невідомого ключа, порожньої бази й повторного читання новим з’єднанням; секрети не зберігати в Git. Поля книги: назва, автор, доступність; видача читачу робить книгу недоступною. Звіт: число видач кожного читача, повторну видачу заборонити.
