# Об’єктно-орієнтоване програмування C# II

Здобувач отримує набір навичок .NET-розробника, з якими працюють у реальних проєктах: від настільних і мобільних застосунків до вебсервісів і баз даних. Кожна тема завершується власним робочим застосунком, тож наприкінці курсу здобувач має портфоліо проєктів і досвід поєднання інтерфейсу, даних, мережі та штучного інтелекту в одному рішенні.

Курс є другою частиною дисципліни «Об’єктно-орієнтоване програмування» і присвячений розробці прикладного програмного забезпечення мовою C# на платформі .NET: настільних застосунків Windows Forms та Windows Presentation Foundation, застосунків для роботи з базами даних (ADO.NET, Entity Framework Core), мережних застосунків, вебсервісів ASP.NET Core та SignalR, кросплатформних застосунків .NET MAUI та застосунків з інтеграцією моделей штучного інтелекту. Під час курсу здобувачі також опановують систему керування версіями Git, регулярні вирази, асинхронне програмування та впровадження залежностей.
