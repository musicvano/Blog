# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Усі перевірки виконуйте у спеціальному робочому каталозі; не використовуйте особисті документи як тестові дані. Задайте формат, UTF-8 для тексту, ліміти й політику наявного цільового файла до початку реалізації.

## Варіанти

### Варіант 1. Облік витрат {#v1}

**1. Початковий рівень.** Створити повну програму Java на JDK 27. Прочитати UTF-8 CSV дата,категорія,копійки без лапок і ком у полях; вивести суму. Використати try-with-resources і окремий тестовий каталог; вивести підписаний результат. Перевірити порожній, неправильний та відсутній файл.

Прочитати UTF-8 CSV дата,категорія,копійки без лапок і ком у полях; вивести суму; записати підсумки за категоріями й журнал неправильних рядків. Використати try-with-resources і окремий тестовий каталог; вивести підписаний результат. Перевірити порожній, неправильний та відсутній файл.

**3. Високий рівень.** Створити повну програму Java на JDK 27.
