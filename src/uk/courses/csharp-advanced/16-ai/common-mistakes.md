# Типові помилки

## Типові помилки

Таблиця 16.4. Типові помилки під час інтеграції моделей {.caption}

| **Проблема** | **Причина** | **Виправлення** |
| --- | --- | --- |
| `HttpRequestException` або «model not found» | сервер Ollama не запущено або модель не завантажено | запустити Ollama, `ollama pull <назва>`, `ollama list` |
| запити дедалі повільніші й дорожчі | історія росте без обмеження | обрізати старі повідомлення, стискати історію |
| функція не викликається | модель не підтримує інструменти або немає `UseFunctionInvocation` | модель із позначкою *tools*, шар `UseFunctionInvocation` |
| `TryGetResult` повертає `false` | модель повернула не JSON або обрізаний JSON | температура 0, більший `MaxOutputTokens`, повторний запит |
| вигадані книги, пункти, методи | галюцинація | дані через функції або RAG, інструкція «не вигадуй», перевірка |
| ключ API в репозиторії | ключ записано в коді або `appsettings.json` | відкликати ключ, зберігати в секретах користувача |
| RAG знаходить не ті фрагменти | різні моделі векторів для індексу й запиту, завеликі фрагменти | одна модель подань, менші фрагменти, поріг подібності |
