# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Кожна умова визначає власні входи й виходи та може виконуватися окремо. Python 3.14, стандартна бібліотека та консольний інтерфейс є достатніми. Анотуйте параметри й результати власних функцій, додайте docstring із межами та одиницями. Списки, кортежі й словники можна використовувати на базовому рівні, показаному в теорії. Власні класи й декоратори не потрібні. `functools.cache` дозволено використовувати як готовий засіб. Для цілих перевіряйте текст до перетворення; для дійсних задайте контракт числового запису з крапкою та перевіряйте скінченність і область значень. У високому рівні потрібні меню, кілька функцій, пакетний запуск і порівняння результатів. Інтерфейс `argparse` адаптуйте зі зразка роботи 1: іменовані параметри задають скалярні дані, повторюваний `--item` приймає записи чи команди з полями через двокрапку. Наприклад, `--item "tea:40" --item "bread:60"` описує дві позиції замовлення. Формат свого запису, одиниці та приклади наведіть у `--help`. Якщо аргументів немає, використайте консольні запити. Збирайте всі значення, перевіряйте їх і лише тоді викликайте функцію обчислення: той самий контракт працює для обох інтерфейсів. Для числових скалярів `argparse` підтримує `type=int` або `type=float`; складений запис розділіть через `split(":")` та перевірте кількість і формат полів до перетворення. `parser.error("повідомлення")` друкує діагностику в stderr і завершує програму з кодом 2. Успішний запуск і `--help` повинні завершитися з кодом 0. Файли поки не обов’язкові. Довідка: <https://docs.python.org/3.14/library/argparse.html>. Усі тарифи, ставки, фізичні коефіцієнти й моделі в задачах навчальні.
