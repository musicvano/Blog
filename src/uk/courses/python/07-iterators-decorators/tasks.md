# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Типізуйте власні функції, для генераторів указуйте тип елемента `Iterator[T]`. Умови визначають навчальні дані; доступ до зовнішніх сервісів не потрібний. Нескінченне джерело обов’язково обмежте на боці споживача. У високому рівні використайте `argparse` зі зразка роботи 1: скалярні дані як іменовані аргументи, повторювані записи `--item` із полями через двокрапку. Документуйте порядок полів у `--help`; без аргументів доступне введення з клавіатури. Помилка має йти в stderr із кодом 2, успіх і довідка – з кодом 0. Порівнюйте потоковий результат із простою реалізацією на невеликому наборі.
