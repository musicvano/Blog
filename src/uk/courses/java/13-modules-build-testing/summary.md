# Підсумки

## Висновки

JPMS задає межі доступу, build-файл – відтворювані інструменти й залежності, JUnit – перевірювані контракти. Разом вони дозволяють розвивати програму без залежності від випадкових налаштувань однієї IDE та готують JDBC і JavaFX-проєкти.
