# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Для всіх рівнів подайте UML-діаграму класів із типами атрибутів, сигнатурами методів і зв’язками. Угоди `_name` та `__name` відображайте на схемі, пояснюючи їх зміст у Python. Валідація належить моделі; `input` і `print` залишайте зовнішньому інтерфейсу. Для високого рівня підтримайте CLI та клавіатурне меню, `--help`, структуровані аргументи `--item` з описаними полями, stderr і код 2 для неправильного вводу; успіх має код 0. Звіти містять вирівняні рядки об’єктів і підсумки. Усі тарифи й фізичні коефіцієнти навчальні; жодні зовнішні рахунки не використовуються.
