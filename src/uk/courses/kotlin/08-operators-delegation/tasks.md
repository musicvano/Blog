# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Подайте UML класів та інтерфейсів. Для операторів письмово задайте семантику, тип результату, межі та правило зміни або незмінності операндів. Для делегата вкажіть власника стану й момент перевірки чи повідомлення. Високий рівень має `--help`, іменовані аргументи й повторюваний `--item` зі структурованим значенням, клавіатуру без аргументів, stderr/код 2 для помилок та код 0 для успіху. Звіт містить таблицю й підсумки. Випадкові демонстрації мають фіксоване зерно або явно задану послідовність для перевірки.

## Порядок виконання та захисту роботи

1. Визначте контракт операцій і накресліть UML.
2. Реалізуйте перевірені конструктори та обмеження чисел.
3. Перевірте оператори без зміни вхідних значень, якщо це контракт типу; окремо перевірте plusAssign, якщо він потрібний.
4. Перевірте межі індексів, порожні діапазони й вичерпання ітератора.
5. Для властивостей перевірте початкове значення, успішний запис, відмову та незмінність стану після неї.
6. Для декоратора перевірте прямі та внутрішні виклики делегата.
7. Подайте код, UML, README і щонайменше п’ять перевірок.
8. На захисті перейдіть від символу операції до функції в IDE та поясніть момент виклику вашого делегата.
