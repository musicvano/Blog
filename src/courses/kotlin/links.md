# Useful links

## Documentation

- [Kotlin documentation](https://kotlinlang.org/docs/home.html) — official language documentation with examples and an API reference
- [Kotlin Standard Library API reference](https://kotlinlang.org/api/core/kotlin-stdlib/) — a reference for Kotlin standard library classes and functions
- [Kotlin coding conventions](https://kotlinlang.org/docs/coding-conventions.html) — official naming, formatting, and idiomatic coding style rules
- [Collections overview](https://kotlinlang.org/docs/collections-overview.html) — lists, sets, maps, and collection operations
- [Coroutines guide](https://kotlinlang.org/docs/coroutines-guide.html) — a guide to coroutines, scopes, context, and cancellation
- [Asynchronous Flow](https://kotlinlang.org/docs/flow.html) — asynchronous Flow data streams, operators, and exception handling
- [Kotlin serialization](https://kotlinlang.org/docs/serialization.html) — serializing objects to JSON with kotlinx.serialization
- [Test code using JUnit in JVM](https://kotlinlang.org/docs/jvm-test-using-junit.html) — configuring and writing unit tests with kotlin.test and JUnit

## Tutorials and practice

- [Kotlin tour](https://kotlinlang.org/docs/kotlin-tour-welcome.html) — a step-by-step introduction to language fundamentals with interactive exercises
- [Kotlin Koans](https://play.kotlinlang.org/koans/overview) — a series of short exercises for practicing syntax directly in the browser
- [Kotlin Playground](https://play.kotlinlang.org/) — an online editor for running and sharing Kotlin code without installation
- [Baeldung Kotlin tutorials](https://www.baeldung.com/kotlin/) — practical articles about the language, coroutines, testing, and libraries

## Tools and libraries

- [IntelliJ IDEA documentation](https://www.jetbrains.com/help/idea/) — documentation for the development environment, debugger, and refactoring tools
- [Gradle User Manual](https://docs.gradle.org/current/userguide/userguide.html) — project builds, dependencies, and Kotlin DSL scripts
- [Git Reference Manual](https://git-scm.com/docs) — a command reference for the Git version control system
- [Exposed documentation](https://www.jetbrains.com/help/exposed/home.html) — relational database access through DSL and DAO
- [Compose Multiplatform](https://kotlinlang.org/docs/multiplatform/compose-multiplatform.html) — creating declarative graphical interfaces for desktop applications
- [Navigation in Compose Multiplatform](https://kotlinlang.org/docs/multiplatform/compose-navigation-routing.html) — navigating between application screens in Compose Multiplatform

## Community, blogs, and videos

- [The Kotlin Blog](https://blog.jetbrains.com/kotlin/) — official news about language, tool, and library releases
- [Kotlin by JetBrains on YouTube](https://www.youtube.com/@Kotlin) — video tutorials, KotlinConf talks, and overviews of new features
