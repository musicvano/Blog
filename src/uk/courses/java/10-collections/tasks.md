# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

У звіті обґрунтуйте вибір інтерфейсу й конкретної реалізації. Порядок виводу повинен бути визначений умовою, а не випадковою поведінкою HashMap.
