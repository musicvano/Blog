# Корисні посилання

## Документація

- [Dev.java](https://dev.java/learn/) — офіційні навчальні матеріали Oracle з мови Java
- [Java SE Documentation](https://docs.oracle.com/en/java/javase/) — довідник API, посібники та інструменти JDK для кожної версії
- [Java Language and Virtual Machine Specifications](https://docs.oracle.com/javase/specs/) — формальний опис синтаксису та семантики мови Java
- [JDK Enhancement Proposals](https://openjdk.org/jeps/0) — описи нових можливостей мови, зокрема записів і зіставлення зі зразком

## Інструменти та бібліотеки

- [IntelliJ IDEA documentation](https://www.jetbrains.com/help/idea/) — робота в середовищі розробки, налагодження та рефакторинг коду
- [Git Reference Manual](https://git-scm.com/docs) — офіційний довідник команд системи керування версіями Git
- [Maven Documentation](https://maven.apache.org/guides/) — посібники зі збирання проєктів і керування залежностями в Maven
- [Gradle User Manual](https://docs.gradle.org/current/userguide/userguide.html) — налаштування збирання, залежностей і задач у Gradle
- [JUnit User Guide](https://docs.junit.org/current/user-guide/) — написання та запуск модульних тестів у JUnit
- [OpenJFX Documentation](https://openjfx.io/openjfx-docs/) — встановлення JavaFX і налаштування проєктів у середовищах розробки
- [Scene Builder](https://gluonhq.com/products/scene-builder/) — візуальний редактор FXML для проєктування інтерфейсу JavaFX

## Бази даних

- [JDBC API (java.sql)](https://docs.oracle.com/en/java/javase/27/docs/api/java.sql/java/sql/package-summary.html) — інтерфейси Connection, PreparedStatement і ResultSet для роботи з базами даних
- [PostgreSQL JDBC Driver](https://jdbc.postgresql.org/documentation/) — підключення до PostgreSQL з Java та параметри драйвера
- [PostgreSQL Documentation](https://www.postgresql.org/docs/current/) — мова SQL, типи даних і можливості СКБД PostgreSQL

## Навчальні посібники та практика

- [Baeldung Java Tutorial](https://www.baeldung.com/java-tutorial) — статті з прикладами щодо мови, колекцій, Stream API і тестування
- [Jenkov Java Tutorials](https://jenkov.com/tutorials/java/index.html) — послідовні посібники з мови Java, колекцій, NIO та JDBC
- [Java Programming MOOC](https://java-programming.mooc.fi/) — безкоштовний курс Гельсінського університету з вправами від основ до ООП
- [Learn Git Branching](https://learngitbranching.js.org/) — інтерактивні вправи з гілками, злиттям і перебазуванням у Git

## Спільнота, блоги та відео

- [Inside.java](https://inside.java/) — новини, статті та подкасти від розробників Java в Oracle
- [Java YouTube channel](https://www.youtube.com/@java) — огляди нових версій Java, доповіді та відеоуроки
