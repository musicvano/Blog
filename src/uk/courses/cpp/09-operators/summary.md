# Підсумки

## Висновки

Операції мають зберігати очікуваний предметний зміст. Інваріант робить порівняння значень узгодженим. Потокове введення має зберігати стан при відмові. Тести перевіряють як результат, так і алгебраїчні закони.

## Питання для самоперевірки

1. Які властивості операції не можна змінити перевантаженням?
2. Коли операція має бути вільною функцією?
3. Чому += повертає посилання, а + значення?
4. Чим відрізняються strong, weak і partial ordering?
5. Чи створює власний spaceship автоматично рівність?
6. Що дає friend і чого він не дає?
7. Для чого потрібні дві версії operator[]?
8. Як розрізняються префіксний і постфіксний ++?
9. Що означає explicit operator bool?
10. Чому operator&lt;&lt; не достатньо для std::println?
11. Як уникнути часткової зміни при >>?
12. Чому порядок полів важливий для defaulted порівняння?
13. Який контракт має m[row, column]?
14. Коли іменований метод кращий за оператор?
15. Як перевірити переповнення до арифметичної операції?
