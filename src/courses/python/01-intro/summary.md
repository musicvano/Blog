# Summary

## Conclusions

CPython executes bytecode, PyCharm organizes development, the environment separates dependencies, and Git stores history. Running a program requires code and the correct interpreter; sharing a project also requires a dependency specification and instructions.

## Self-check questions

1. How does the Python language differ from CPython and PyPy?
2. How do you choose a Python branch for a learning project?
3. How does bytecode differ from source code?
4. Why might `__pycache__` not appear after running a script?
5. Where do you enter shell commands, and where do you enter Python expressions?
6. What are `main()` and the `__name__` check for?
7. How do you read a traceback and find the line with the error?
8. How do *Run*, *Python Console*, and *Terminal* differ?
9. How do you verify the project interpreter?
10. Is activating a virtual environment required?
11. Why is the `python -m pip` form useful?
12. What does `requirements.txt` store, and what does it not describe?
13. What does uv use `pyproject.toml` and `uv.lock` for?
14. How do the working directory, staging area, and repository differ?
15. Which files must you share to reproduce a lab assignment?
