# Підсумки

## Висновки

Спеціальні форми класів допомагають виразити структуру даних і допустимі стани. Data-клас підтримує операції над значенням, enum описує константи, sealed – варіанти з різними даними. Object і companion визначають спосіб доступу та створення, а value class відокремлює змістовні ідентифікатори.

2. Чому copy не є глибоким копіюванням?
3. Як порядок конструктора пов’язаний із деструктуризацією?
4. Чому ordinal не підходить для стабільного коду?
5. Коли enum недостатньо і потрібний sealed-тип?
6. Які межі має закритість sealed-ієрархії?
7. Чому вичерпний when корисний під час розширення моделі?
8. Чи робить потокобезпечна ініціалізація object усі його методи безпечними?
9. Чим компаньйон відрізняється від екземпляра класу?
10. Чим value class відрізняється від typealias?
