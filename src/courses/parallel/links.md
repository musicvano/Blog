# Useful links

## Parallel programming in .NET

- [Parallel programming in .NET](https://learn.microsoft.com/en-us/dotnet/standard/parallel-programming/) — the official guide to TPL, PLINQ, and thread-safe collections
- [Managed threading](https://learn.microsoft.com/en-us/dotnet/standard/threading/) — threads, the thread pool, and synchronization primitives in .NET
- [System.Threading.Channels](https://learn.microsoft.com/en-us/dotnet/core/extensions/channels) — channels for the producer–consumer pattern, with examples
- [Asynchronous programming with async and await](https://learn.microsoft.com/en-us/dotnet/csharp/asynchronous-programming/) — the task-based asynchronous programming model in C#
- [SIMD-accelerated types in .NET](https://learn.microsoft.com/en-us/dotnet/standard/simd) — vector types and hardware-accelerated computation in .NET

## High-performance computing: OpenMP, CUDA, MPI

- [cppreference.com — Concurrency support library](https://en.cppreference.com/w/cpp/thread) — a reference for C++ threads, mutexes, atomic operations, and futures
- [OpenMP Specifications](https://www.openmp.org/specifications/) — official OpenMP specifications and reference cards
- [CUDA Programming Guide](https://docs.nvidia.com/cuda/cuda-programming-guide/) — the official guide to programming NVIDIA GPUs
- [ILGPU Documentation](https://ilgpu.net/docs/) — GPU computing in C# with the ILGPU library
- [Open MPI Documentation](https://docs.open-mpi.org/en/main/) — installation, execution, and the Open MPI function reference
- [Slurm Workload Manager Documentation](https://slurm.schedmd.com/documentation.html) — configuring a cluster and submitting jobs through the Slurm scheduler

## Distributed systems and the cloud

- [gRPC Documentation](https://grpc.io/docs/) — concepts, guides, and examples of remote procedure calls with gRPC
- [RabbitMQ Documentation](https://www.rabbitmq.com/docs) — queues, exchanges, and reliable message delivery in RabbitMQ
- [Microsoft Orleans documentation](https://learn.microsoft.com/en-us/dotnet/orleans/) — the virtual actor model and distributed .NET applications
- [Docker Docs](https://docs.docker.com/get-started/) — containerization basics, images, and Docker Compose
- [Kubernetes Documentation](https://kubernetes.io/docs/home/) — concepts, guides, and a reference for Kubernetes container orchestration
- [Aspire Documentation](https://aspire.dev/docs/) — orchestration, telemetry, and deployment of distributed .NET applications

## Theory and architecture

- [Introduction to Parallel Computing Tutorial (LLNL)](https://hpc.llnl.gov/documentation/tutorials/introduction-parallel-computing-tutorial) — architectures, parallelism models, and parallel program design
- [The Art of HPC (V. Eijkhout)](https://theartofhpc.com/) — free textbooks on HPC, parallel algorithms, MPI, and OpenMP
- [Microservice Architecture Patterns](https://microservices.io/patterns/) — a catalog of microservice patterns: API gateway, saga, Outbox
