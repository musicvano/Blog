# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

## Варіанти

### Варіант 1. Калькулятор {#v1}

**1. Початковий рівень.** Створити самостійний JavaFX-застосунок «Калькулятор»: сітка кнопок, історія обчислень, керування з клавіатури. Реалізувати основну дію через форму з підписаними полями й кнопкою, показати результат або помилку на тому самому екрані. Використати компонування без абсолютних координат і перевірити порожнє введення та межі значень. Ввести два скінченні числа й операцію +, −, × або ÷; показати результат, ділення на нуль відхилити.

**2. Базовий рівень.** Створити самостійний JavaFX-застосунок «Калькулятор»: сітка кнопок, історія обчислень, керування з клавіатури. Реалізувати повний сценарій теми, список історії дій зі стабільними ідентифікаторами, вибір режиму та діалог підтвердження очищення. Винести обчислення в окремий клас, додати CSS, роботу Enter і зміну розміру вікна; скасування діалогу залишає дані без змін. Ввести два скінченні числа й операцію +, −, × або ÷; показати результат, ділення на нуль відхилити.

**3. Високий рівень.** Створити самостійний JavaFX-застосунок «Калькулятор»: сітка кнопок, історія обчислень, керування з клавіатури. Відділити модель від UI, реалізувати FXML-форму, перевірку введення, збереження налаштувань і повідомлення про помилки. Додати `--help`, `--config=path`, `--check=field:value,...`; останній режим виконує предметну перевірку без відкриття GUI та друкує вирівняну таблицю з підсумком. Помилки до stderr, коди 0/2/1. Для звичайного запуску показати GUI; додати JUnit-тести моделі, перевірити клавіатурний фокус і підготувати локальний runtime без встановлення в систему. Ввести два скінченні числа й операцію +, −, × або ÷; показати результат, ділення на нуль відхилити.
