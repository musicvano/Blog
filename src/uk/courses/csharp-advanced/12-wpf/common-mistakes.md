# Типові помилки

## Типові помилки

У табл. 12.3 наведено помилки, яких найчастіше припускаються під час переходу від Windows Forms до WPF.

Таблиця 12.3. Типові помилки в застосунках WPF {.caption}

| **Проблема** | **Причина** | **Виправлення** |
| --- | --- | --- |
| елементи накладаються один на одний у `Grid` | не задано `Grid.Row`, `Grid.Column` (усі в клітинці 0,0) | задати приєднані властивості або використати `StackPanel` |
| після зміни розміру вікна частина форми обрізана або порожня | фіксовані `Width`, `Height`, `Margin` з конструктора, `Canvas` для форми | `Grid` з `Auto` і `*`, `MinWidth`, `SizeToContent` |
| обробник `MouseDown` на панелі не спрацьовує після клацання кнопки | кнопка позначила подію обробленою | `Click`, `PreviewMouseDown` або `AddHandler(…, true)` |
| `XamlParseException` під час запуску | помилка в атрибуті, ресурс не знайдено, файл не має дії *Resource* | прочитати `InnerException`, перевірити ключ і *Build Action* |
| помилка WPF0001 під час збирання | `ThemeMode` в коді – експериментальний API | `#pragma warning disable WPF0001` або `NoWarn` |
| code-behind розростається, елементи шукають за іменами | логіка інтерфейсу й даних змішана | прив’язка даних і патерн MVVM (тема 13) |
