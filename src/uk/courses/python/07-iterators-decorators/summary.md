# Підсумки

## Висновки

Ітератор відокремлює отримання наступного елемента від його обробки. Генератор реалізує цей контракт через `yield`, а `itertools` поєднує готові схеми обходу. Лямбда доречна для короткого локального правила; декоратор – для спільної поведінки навколо виклику. В обох випадках читабельність і явно визначений контракт важливіші за скорочення кількості рядків.
