# Підсумки

## Висновки

Операторні угоди роблять власний тип природним у виразах, якщо символ зберігає очікувану семантику. Делегати відокремлюють повторювану логіку доступу, а делегування інтерфейсу допомагає композиції. У кожному механізмі важливі момент виконання, власник стану й перевірений контракт.

1. Чому operator не дозволяє вигадати новий символ?
2. Чим plusAssign відрізняється від plus із присвоєнням?

4. На якому об’єкті викликається contains для `x in a`?
5. Які методи потрібні для повторного перебору діапазону?
6. Що одержують getValue та setValue?
7. Коли lazy повторно викликає ініціалізатор?
8. Чим момент observable відрізняється від vetoable?
9. Для чого потрібний provideDelegate?
10. Чому внутрішній виклик делегата обходить override обгортки?
