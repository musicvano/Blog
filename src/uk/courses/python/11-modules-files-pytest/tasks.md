# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Python 3.14; усі функції мають анотації. Формати файлів, кодування, розділювач CSV, поля та одиниці запишіть у README. Помилка вхідних даних не повинна мовчки створювати правдоподібний неповний результат. Тести виконують файлові зміни тільки в `tmp_path`.

## Варіанти

### Варіант 1. Облік витрат {#v1}

**1. Початковий рівень.** Створити консольну програму з анотованими функціями. Вхід передавати шляхом у командному рядку; поля або параметри: `category,date,cents`. Перевірити: дата ISO, непорожня категорія, додатні цілі копійки. Обчислити й вивести суму копійок за категоріями. Для табличних даних читати UTF-8 CSV із розділювачем ;, для папок виконати описаний обхід. Подати два pytest-тести обчислення.

**2. Базовий рівень.** Створити консольну програму з анотованими функціями. Вхід передавати шляхом у командному рядку; поля або параметри: `category,date,cents`. Перевірити: дата ISO, непорожня категорія, додатні цілі копійки. Обчислити й вивести суму копійок за категоріями. Організувати код у пакет із точкою входу -m та argparse. Для табличних даних читати JSON-масив об’єктів; файлові задачі приймають шляхи. Зберегти результат у JSON за окремим шляхом. Додати pytest-тести успіху, порожніх даних і помилки.

**3. Високий рівень.** Створити консольну програму з анотованими функціями. Вхід передавати шляхом у командному рядку; поля або параметри: `category,date,cents`.
