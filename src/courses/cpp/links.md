# Useful links

## Documentation and the standard

- [cppreference.com](https://en.cppreference.com/w/cpp) — reference for the C++ language and standard library, with examples
- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) — rules for modern C++ by B. Stroustrup and H. Sutter
- [Microsoft C/C++ documentation](https://learn.microsoft.com/en-us/cpp/) — documentation for MSVC, its libraries and building projects in Visual Studio
- [C++ Language Reference (Microsoft Learn)](https://learn.microsoft.com/en-us/cpp/cpp/cpp-language-reference) — the syntax and semantics of C++, with examples
- [Microsoft C/C++ language conformance](https://learn.microsoft.com/en-us/cpp/overview/visual-cpp-language-conformance) — which C++ standard features the MSVC compiler supports
- [C++ Standard Draft](https://eel.is/c++draft/) — the current draft of the C++ standard, browsable by section

## Learning resources and practice

- [LearnCpp](https://www.learncpp.com) — a free step-by-step C++ tutorial, from the basics to OOP
- [Welcome back to C++ (Modern C++)](https://learn.microsoft.com/en-us/cpp/cpp/welcome-back-to-cpp-modern-cpp) — an overview of modern C++ idioms: RAII, smart pointers, containers
- [hacking C++](https://hackingcpp.com) — illustrated cheat sheets and lessons on the C++ standard library
- [Exercism C++ Track](https://exercism.org/tracks/cpp) — exercises with automated tests and mentor reviews

## Environment and tools

- [Visual Studio debugger feature tour](https://learn.microsoft.com/en-us/visualstudio/debugger/debugger-feature-tour) — breakpoints, stepping through code and inspecting variables
- [CMake projects in Visual Studio](https://learn.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio) — creating, building and debugging CMake projects in Visual Studio
- [CMake Tutorial](https://cmake.org/cmake/help/latest/guide/tutorial/index.html) — the official step-by-step guide to building projects with CMake
- [Git Reference Manual](https://git-scm.com/docs) — the official reference for the commands of the Git version control system
- [Compiler Explorer](https://godbolt.org) — compile code online with different compilers and see the assembly
- [C++ Insights](https://cppinsights.io) — shows how the compiler expands templates, lambdas and loops

## Community, blogs and videos

- [Standard C++ Foundation](https://isocpp.org) — news about the standard, articles and answers to frequently asked questions
- [C++ Stories](https://www.cppstories.com) — B. Filipek's blog about new features of the C++ standards
- [CppCon](https://www.youtube.com/@CppCon) — recordings of talks from the largest C++ conference
- [C++ Weekly With Jason Turner](https://www.youtube.com/@cppweekly) — short weekly videos about C++ techniques and features
