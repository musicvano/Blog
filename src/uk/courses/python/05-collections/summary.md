# Підсумки

## Висновки

Список зручний для змінної послідовності, кортеж – для фіксованого запису, множина – для унікальності, словник – для доступу за ключем. `Counter`, `defaultdict` і `deque` спрощують часті операції, якщо їх поведінка збігається з правилами задачі. Копіювання, порядок і хешованість є частиною контракту програми.

## Питання для самоперевірки

1. Які властивості розрізняють список, кортеж, множину та словник?
2. Чим індекс поза межами відрізняється від зрізу поза межами?
3. Як працює від’ємний крок і чому `step=0` заборонений?
4. Чим `append` відрізняється від `extend`?
5. Що повертають `sort`, `sorted` та `pop`?
6. Чому сортування за кортежем ключів зручне для рейтингу?
7. Як побудувати незалежні рядки матриці?
8. Що копіює `copy`, а що – `deepcopy`?
9. Чому кортеж зі списком не є придатним ключем словника?
10. Чим відрізняються різниця та симетрична різниця множин?
11. Коли `get` і `setdefault` дають різні наслідки для словника?
12. Які зміни колекції небезпечні під час обходу?
13. Як `Counter.subtract` відрізняється від оператора віднімання?
14. Для чого потрібні `maxlen`, `OrderedDict` і `ChainMap`?
15. Чому `insort` має O(n), хоча пошук місця має O(log n)?
