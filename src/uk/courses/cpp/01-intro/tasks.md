# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Для цієї вступної теми дані задають у коді. Складність зростає завдяки оформленню результату, перевірці обчислень, відтворюваному збиранню та історії Git. Не потрібно вводити класи чи розбирати аргументи командного рядка, якщо цього не вимагає умова.

## Варіанти

### Варіант 1. Візитна картка студента {#v1}

**1. Початковий рівень.** Створити консольну програму, яка без введення з клавіатури виводить задані в коді навчальні ім’я, групу та спеціальність окремими підписаними рядками.

**2. Базовий рівень.** Створити консольну програму, яка виводить дві вигадані візитні картки з ім’ям, групою та навчальною адресою пошти. Дані задати в коді, картки оформити рамками однакової ширини та перевірити вирівнювання для короткого й довгого імені.

**3. Високий рівень.** Створити консольний проєкт, який виводить три вигадані картки студентів із заданих у коді даних, без клавіатурного введення. Оформити рамки й заголовок, додати README з командою збирання та очікуваним виведенням. У локальному Git зберегти три змістовні коміти: початкова картка, форматування, третя картка; виключити результати збирання через `.gitignore`.

### Варіант 2. Меню кав’ярні {#v2}

**1. Початковий рівень.** Створити консольну програму, яка виводить назви й ціни трьох напоїв, задані в коді; введення від користувача не потрібне.

**2. Базовий рівень.** Створити консольну програму, яка для заданих у коді трьох напоїв і двох десертів друкує меню з категоріями та цінами з двома десятковими знаками. Перевірити вирівнювання назв різної довжини; введення не використовувати.

**3. Високий рівень.** Створити консольний проєкт меню п’яти заданих у коді позицій, який без введення друкує категорії, ціни й вартість набору «кава та десерт». У локальному Git створити гілку `new-drink`, додати шосту позицію, перевірити виведення та злити гілку в `main`. Додати README з командами збирання й порівнянням меню до та після зміни; результати збирання ігнорувати.

### Варіант 3. Розклад занять {#v3}

**1. Початковий рівень.** Створити консольну програму, яка виводить заданий у коді розклад трьох пар одного дня: номер, початок і назву дисципліни. Введення не потрібне.

**2. Базовий рівень.** Створити консольну програму, яка без введення виводить розклад двох днів по три пари з кодових даних у стовпцях «день», «час», «дисципліна», «аудиторія». Для одного заняття вказати дистанційний формат замість номера аудиторії.

**3. Високий рівень.** Створити консольний проєкт розкладу двох днів по три пари із заданими в коді часом, дисциплінами й аудиторіями. Вивести таблицю без введення, зібрати її у Visual Studio та Developer PowerShell, порівняти результати. Зберегти початковий розклад і перенесення однієї пари окремими комітами; у README записати команду збирання та причину перенесення.

### Варіант 4. Квиток на потяг {#v4}

**1. Початковий рівень.** Створити консольну програму, яка виводить вигаданий квиток: станції відправлення й прибуття, номер потяга та місце. Дані задати в коді.

**2. Базовий рівень.** Створити консольну програму, яка виводить два вигадані квитки із заданими в коді маршрутом, датою, часом, вагоном, місцем і ціною. Оформити однакові рамки та ціни з двома десятковими знаками; клавіатурного введення немає.

**3. Високий рівень.** Створити консольний проєкт, який без введення друкує два вигадані квитки з кодових даних і загальну вартість. Зберегти в Git початкову версію, додавання другого квитка та зміну часу трьома комітами. Додати `.gitignore` й README з командою збирання; показати різницю коміту зі зміною часу.

### Варіант 5. Прямокутна кімната {#v5}

**1. Початковий рівень.** Створити консольну програму, яка для заданої в коді кімнати 4 м на 5 м обчислює площу підлоги й периметр, виводить значення з одиницями без введення.

**2. Базовий рівень.** Створити консольну програму, яка для кімнати 4 м на 5 м заввишки 2,8 м обчислює площу чотирьох стін без урахування прорізів і вартість фарбування за 85 грн/м². Дані задати в коді; вивести вихідні дані й результати з двома десятковими знаками, без клавіатурного введення.

**3. Високий рівень.** Створити консольний проєкт кошторису двох кімнат 4 м на 5 м і 3 м на 4 м, висота обох 2,8 м, фарбування стін без прорізів коштує 85 грн/м². Дані задати в коді, вивести площі, вартості й підсумок без введення. Зібрати Debug і Release, порівняти виведення, записати результати в README; код, README та `.gitignore` зберегти в локальному Git.

### Варіант 6. Чек магазину {#v6}

**1. Початковий рівень.** Створити консольну програму, яка для двох заданих у коді товарів виводить назви, ціни та суму покупки. Кількість кожного товару – одна одиниця; введення немає.

**2. Базовий рівень.** Створити консольну програму, яка для трьох товарів із заданими в коді цінами та кількостями виводить табличний чек, суму до знижки, знижку 10 % і суму до сплати. Використати дві десяткові цифри; введення не потрібне.

**3. Високий рівень.** Створити консольний проєкт чека трьох заданих у коді товарів із цінами, кількостями й знижкою 10 %. Без введення вивести позиції та підсумки. У Git окремо зафіксувати чек, знижку та README з розрахунком контрольної суми й командою збирання. Підготувати репозиторій до передавання викладачеві: додати `.gitignore` і перевірити, що `.exe` та `.obj` не відстежуються.

### Варіант 7. Прогноз погоди {#v7}

**1. Початковий рівень.** Створити консольну програму, яка виводить навчальний прогноз на три дні: дату, температуру та опис погоди з даних у коді, без введення й мережевих запитів.

**2. Базовий рівень.** Створити консольну програму, яка виводить таблицю навчального прогнозу на п’ять днів із заданими в коді денною й нічною температурами. Використати від’ємні, нульові й додатні значення, підписати одиниці; введення відсутнє.

**3. Високий рівень.** Створити консольний проєкт навчального прогнозу на п’ять днів із заданими в коді денними й нічними температурами; вивести таблицю без введення. У Git зберегти початковий прогноз і його оновлення окремими комітами, поставити тег `v1.0` на початкову версію. У README пояснити різницю даних і записати команду перегляду версії з тегом; результати збирання ігнорувати.

### Варіант 8. Табло футбольного матчу {#v8}

**1. Початковий рівень.** Створити консольну програму, яка виводить назви двох вигаданих команд, рахунок і хвилину матчу із заданих у коді даних. Введення не використовувати.

**2. Базовий рівень.** Створити консольну програму, яка для заданого в коді вигаданого матчу виводить рахунок і таблицю ударів, кутових та попереджень двох команд. Передбачити нульове значення в одному показнику; введення не потрібне.

**3. Високий рівень.** Створити консольний проєкт табло вигаданого матчу з кодовими даними: команди, рахунок, удари, кутові та попередження. Вивести таблицю без введення. Зафіксувати початковий код у Git, у гілці `fix-score` виправити навмисно неправильний рахунок, перевірити виведення й злити гілку. У README пояснити виправлення та навести правильний результат; додати `.gitignore`.

### Варіант 9. Паспорт автомобіля {#v9}

**1. Початковий рівень.** Створити консольну програму, яка друкує марку вигаданого автомобіля, рік випуску й об’єм бака із заданих у коді даних, без введення.

**2. Базовий рівень.** Створити консольну програму, яка для автомобіля з пробігом поїздки 240 км і витраченими 18 л пального обчислює витрату в л/100 км. Дані задати в коді; вивести паспорт, вихідні дані й результат з двома десятковими знаками.

**3. Високий рівень.** Створити консольний проєкт, який без введення виводить дані двох навчальних поїздок: 240 км і 18 л, 360 км і 25,2 л; обчислює витрату кожної та спільну витрату на 100 км за сумарними даними. Зберегти реалізацію в Git трьома комітами, додати `.gitignore` і README з ручною перевіркою спільної витрати.

### Варіант 10. Бібліотечний формуляр {#v10}

**1. Початковий рівень.** Створити консольну програму, яка виводить автора, назву книги й навчальний інвентарний номер, задані в коді. Даних із клавіатури не зчитувати.

**2. Базовий рівень.** Створити консольну програму, яка виводить формуляр двох вигаданих книг: автор, назва, дата видачі та строк повернення. Дати й решту даних задати текстом у коді; вирівняти поля та не обчислювати календарні інтервали.

**3. Високий рівень.** Створити консольний проєкт формуляра трьох вигаданих книг із заданими в коді назвами, авторами й текстовими датами видачі та повернення. Вивести таблицю без введення. У локальному Git зафіксувати початковий формуляр і зміну строку повернення окремими комітами через Git Changes; додати README з поясненням зміни й `.gitignore` для службових файлів.

### Варіант 11. Навчальна етикетка {#v11}

**1. Початковий рівень.** Створити консольну програму, яка виводить етикетку вигаданого навчального продукту: назву «Зразок A», масу 50 г і напис «Не для споживання». Дані задати в коді; введення не потрібне.

**2. Базовий рівень.** Створити консольну програму, яка для двох навчальних зразків масою 50 г і 80 г виводить назву, масу та масу умовного компонента із часткою 5 %. Дані задані в коді, введення немає; додати напис «Не для споживання», оформити однакові рамки та результати з двома десятковими знаками.

**3. Високий рівень.** Створити консольний проєкт двох етикеток навчальних зразків масою 50 г і 80 г з умовним компонентом 5 %. Вивести маси компонента й напис «Не для споживання» без введення. Зібрати `cl` з `/W4`, усунути попередження, зберегти команду й контрольні результати в README. У Git зафіксувати код, документацію та `.gitignore`; не використовувати медичні рекомендації.

### Варіант 12. Посадковий талон {#v12}

**3. Високий рівень.** Створити консольний проєкт двох вигаданих посадкових талонів із кодовими даними маршруту, рейсу, часу, місця й виходу; вивести рамки без введення. Зібрати Debug і Release та перевірити збіг тексту. Зберегти проєкт у Git, додати `.gitignore` та README із шляхами до збірок і результатом порівняння.

У Git зберегти три версії: чотири порції, додані дві, додані вісім; у README навести контрольні розрахунки та команду збирання, додати `.gitignore`.

Зберегти код у Git, навмисно змінити тариф у робочому файлі, переглянути різницю й відновити лише цю зміну, збережену у файлі, але не в коміті. ### Варіант 17. Табель успішності {#v17}
