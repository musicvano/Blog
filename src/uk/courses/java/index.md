# Об’єктно-орієнтоване програмування Java

Java – одна з найзатребуваніших мов на ринку праці: на ній працюють банківські, телекомунікаційні та хмарні сервіси, корпоративні та Android-застосунки. Курс веде від перших програм до завершених застосунків і знайомить з інструментами, якими користуються професійні команди розробників.

Курс присвячено вивченню мови програмування Java на платформі JDK 27 у середовищі IntelliJ IDEA – від базових конструкцій мови до об’єктно-орієнтованого та узагальненого програмування, колекцій і Stream API, роботи з файлами, модульної системи, систем збирання Maven і Gradle та модульного тестування. На завершальному етапі здобувачі навчаються працювати з базами даних засобами JDBC і створювати графічні застосунки на JavaFX. Кожна тема курсу поєднує лекцію з лабораторною роботою.
