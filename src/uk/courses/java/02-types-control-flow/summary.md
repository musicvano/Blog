# Підсумки

## Висновки

Тип, діапазон, формат введення й умова завершення разом утворюють контракт базового алгоритму. Перевірка потрібна не лише перед арифметикою: результат операції також може вийти за допустимі межі.

## Питання для самоперевірки

1. Чим var відрізняється від динамічного типу?
2. Чому long не виправляє вже переповнений добуток int?
3. Коли розширення типу втрачає точність?
4. Чим цілочисельне ділення відрізняється від дійсного?
5. Як працює коротке замикання?
6. Чому hasNextInt не споживає неправильний токен?
7. Що залишається після nextInt перед nextLine?
8. Для чого потрібний yield у switch-виразі?
9. Які дії виконує continue у for?
10. Як довести, що цикл завершиться?
