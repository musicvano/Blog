# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Усі завдання є графічними застосунками Python 3.14/PySide6. Зберігайте предметні обчислення в окремих типізованих функціях, показуйте помилки у формі, використовуйте компонування. Неправильне введення не повинно закривати програму або залишати хибний результат без пояснення. Зовнішні API не потрібні.

## Порядок виконання та захисту роботи

1. Підготуйте `.venv`, зафіксуйте версію PySide6 і перевірте вибраний інтерпретатор PyCharm.
2. Намалюйте ескіз форми, визначте типи полів, одиниці, межі та стан кнопок для порожнього введення.
3. Реалізуйте й перевірте чисті функції обчислень до підключення інтерфейсу. Додайте анотації методів і слотів.
4. Побудуйте форму, підключіть сигнали один раз, додайте зрозумілі повідомлення валідації й клавіатурний доступ.
5. Перевірте звичайний випадок, межі, неправильне введення, повторні натискання, скидання та зміну розміру вікна. Для таймерів перевірте паузу й повторний старт.
6. Збережіть код, `.ui`, ресурси та README із запуском і фактичними результатами. Додайте pytest-перевірки обчислень для високого рівня та справжній скриншот Windows зі світлою темою.
7. На захисті поясніть дерево володіння, цикл подій, сигнатури сигналів, валідацію й спосіб уникнення блокування вікна.
