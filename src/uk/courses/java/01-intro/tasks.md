# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

## Варіанти

### Варіант 1. Витрата пального {#v1}

**1. Початковий рівень.** Створити консольну програму Java на JDK 27: відстань d км 0..10000, витрата r л/100 км 0..50, ціна p грн/л 0..1000; вивести літри d\*r/100 та вартість d\*r\*p/100. Параметри задати в коді. Вивести підписані результати; дробові числа з двома знаками, якщо умова не задає інше. Подати ручний контрольний розрахунок.

**2. Базовий рівень.** Створити консольну програму Java на JDK 27: відстань d км 0..10000, витрата r л/100 км 0..50, ціна p грн/л 0..1000; вивести літри d\*r/100 та вартість d\*r\*p/100. Параметри читати з клавіатури через Scanner; перевірити формат і межі, вивести підписані результати та опис відмови. Подати README з командами компіляції/запуску та три змістовні коміти Git.

**3. Високий рівень.** Створити консольну програму Java на JDK 27: відстань d км 0..10000, витрата r л/100 км 0..50, ціна p грн/л 0..1000; вивести літри d\*r/100 та вартість d\*r\*p/100. Параметри приймати через CLI у форматі ключ=значення, без аргументів запитувати з клавіатури. Додати `--help`, перевірку формату, скінченності чисел і меж; помилки друкувати в stderr, коди 0 – успіх/довідка, 2 – неправильний ввід, 1 – операційний збій. Вивести вирівняний звіт із підсумком. Подати не менше п’яти контрольних випадків, README й локальну історію Git.
