# Підсумки

## Висновки

Модель є контрактом між даними й представленням. Правильні ролі, індекси й сигнали важливі так само, як правильне число у клітинці. Діалог підтверджує підготовлені дані, проксі змінює їх видимість, а транзакція забезпечує узгоджене збереження. Поділ відповідальності дозволяє перевіряти ці механізми незалежно.
