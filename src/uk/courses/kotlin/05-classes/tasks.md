# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

У кожному рівні потрібна UML-діаграма класів із властивостями, видимістю, конструкторами й методами. Модель не читає консоль; код введення окремо перетворює текст і показує помилки. Для високого рівня використайте CLI з `--help`, іменованими аргументами та повторюваним `--item` зі структурованим значенням; за відсутності аргументів запропонуйте введення з клавіатури. Помилку друкуйте в `System.err`, завершуйте з кодом 2; успішний запуск має код 0. Звіт містить таблицю й підсумок. Тарифи, паролі, медичні й фінансові сюжети є навчальними локальними моделями з явно заданими правилами.
