# Об’єктно-орієнтоване програмування C++

Знання C++ відкриває шлях до розробки системного програмного забезпечення, ігрових рушіїв, вбудованих систем і високопродуктивних обчислень – галузей, де найважливіші швидкодія та контроль над ресурсами. Курс не потребує попереднього досвіду роботи з C++ і одразу вчить сучасного стандарту C++26, а розуміння роботи пам’яті та об’єктів полегшує опанування будь-якої іншої мови.

Курс розраховано на здобувачів без досвіду програмування мовою C++. Він присвячений вивченню мови C++ відповідно до стандарту C++26 у середовищі Microsoft Visual Studio 2026: від базових конструкцій мови, функцій і керування пам’яттю до об’єктно-орієнтованого програмування, шаблонів, концептів, стандартної бібліотеки C++, роботи з файлами та модулів. Кожна тема курсу поєднує лекцію з лабораторною роботою.
