# Підсумки

## Висновки

Власник відповідає за одне завершення ресурсу. Копія та переміщення мають різні контракти джерела. RAII прив’язує очищення до життя об’єкта. Правило нуля відокремлює модель від ручного володіння.

9. Чому return std::move(local) може завадити NRVO?
