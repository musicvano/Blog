# Підсумки

## Висновки

Платформа .NET складається із середовища виконання CLR, бібліотеки базових класів та інструментів розробки й працює в Windows, Linux і macOS. Програма мовою C# компілюється в проміжну мову IL, яку CLR перетворює на машинний код під час виконання, керуючи пам’яттю та безпекою типів. Для розробки потрібен .NET SDK, а середовище розробки можна обрати залежно від операційної системи: Visual Studio 2026, Visual Studio Code з C# Dev Kit або JetBrains Rider. Усі вони використовують інструмент dotnet CLI. Програма організована в проєкти та рішення, її виконання починається з точки входу – методу `Main` або операторів верхнього рівня, а для взаємодії з користувачем використовується клас `Console`.
