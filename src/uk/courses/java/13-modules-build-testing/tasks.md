# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

## Варіанти

### Варіант 1. Бібліотека геометрії {#v1}

**1. Початковий рівень.** Створити самостійну консольну Java-програму «Бібліотека геометрії». Для кола з радіусом r≥0 обчислити площу `π*r*r` і довжину `2*π*r`; нечисловий радіус відхилити. Винести обчислення в окремий клас. Створити Maven-проєкт і щонайменше чотири тести JUnit: типовий випадок, межа, порожні або нульові дані та неправильне введення.

**2. Базовий рівень.** Створити самостійний Java-проєкт «Бібліотека геометрії»: модулі API і застосунку, тести обчислень JUnit. Відділити бібліотеку предметної логіки від консольного клієнта, описати їх залежності та публічний API. Для кола з радіусом r≥0 обчислити площу `π*r*r` і довжину `2*π*r`; нечисловий радіус відхилити. Клієнт виводить таблицю результатів. Додати параметризовані тести для щонайменше шести наборів та тести винятків; збирання й запуск виконувати через Wrapper, пояснити дерево залежностей.

**3. Високий рівень.** Створити самостійний модульний Java-проєкт «Бібліотека геометрії»: модулі API і застосунку, тести обчислень JUnit. Для кола з радіусом r≥0 обчислити площу `π*r*r` і довжину `2*π*r`; нечисловий радіус відхилити. Виділити бібліотеку API та CLI, задати JPMS-дескриптори й відтворюване збирання Maven або Gradle. Приймати `--input=path`, `--options=name:value,...`, `--help`, без аргументів запитувати дані з клавіатури; друкувати вирівняну таблицю та підсумки. Помилки до stderr, коди 0/2/1 для успіху, введення й збою. Додати тести предметних інваріантів, граничних значень і помилок, створити образ jlink та перевірити запуск із чистої робочої теки.
