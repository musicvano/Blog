# Підсумки

## Висновки

Методи відділяють контракт від способу виконання, масиви групують однотипні дані, а рядкові API дозволяють явно обрати буквальну, Unicode або шаблонну обробку. Правильність залежить від меж, порожніх наборів, копіювання та одиниць індексації.

1. Що копіюється під час передавання масиву?
2. Чи можна перевантажити метод лише типом результату?
3. Як varargs поводиться без аргументів?
4. Які дві умови потрібні рекурсії?
5. Чим порожній масив відрізняється від null?
6. Яку передумову має binarySearch?
7. Чому два рядки не порівнюють через посилальну рівність?
8. Чим codePoints відрізняється від chars?
9. Коли потрібний StringBuilder?
10. Чому formatted не замінює екранування HTML?
