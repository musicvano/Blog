# Courses

Courses in object-oriented programming with C++, C#, Java, Kotlin and Python, and in parallel and distributed computing. Every topic consists of a lecture divided into chapters, worked examples, task variants at three levels of difficulty, and review questions.

## Object-Oriented Programming in C++

From the first program in Visual Studio 2026 to classes, templates, containers, ranges and C++26 modules. 16 topics in three modules.

[Go to the course →](/courses/cpp/)

## Available in Ukrainian

These courses are being translated into English. Meanwhile, you can study them in Ukrainian:

- [Object-Oriented Programming in C#](/uk/courses/csharp/) — the .NET platform, classes, interfaces, generics, LINQ, files, SOLID and unit testing
- [C# and .NET Technologies](/uk/courses/csharp-advanced/) — Git, regular expressions, Windows Forms, async/await, ADO.NET and Entity Framework Core, networking, REST and SignalR, WPF, .NET MAUI and AI integration
- [Object-Oriented Programming in Java](/uk/courses/java/) — JDK 27 and IntelliJ IDEA, classes, records, generics, collections, the Stream API, JDBC and JavaFX
- [Object-Oriented Programming in Kotlin](/uk/courses/kotlin/) — null safety, data classes, generics, collections, coroutines, Exposed and Compose Multiplatform
- [Object-Oriented Programming in Python](/uk/courses/python/) — Python 3.14 and PyCharm, classes and protocols, pytest, SQLite, NumPy and pandas, PySide6 and packaging
- [Parallel and Distributed Computing](/uk/courses/parallel/) — threads, TPL and PLINQ, SIMD, OpenMP, CUDA, MPI, a Slurm cluster, RabbitMQ, Orleans, Docker and Kubernetes
