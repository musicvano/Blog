# Useful links

## Documentation

- [Python documentation](https://docs.python.org/3/) — official documentation for the language and standard library
- [The Python Tutorial](https://docs.python.org/3/tutorial/) — the official guide to language fundamentals, from syntax to classes
- [Python Data Model](https://docs.python.org/3/reference/datamodel.html) — special methods, protocols, and Python object behavior
- [Regular Expression HOWTO](https://docs.python.org/3/howto/regex.html) — an introduction to regular expressions and the re module
- [typing — Support for type hints](https://docs.python.org/3/library/typing.html) — type hints, generics, and protocols
- [sqlite3 — DB-API 2.0 interface for SQLite databases](https://docs.python.org/3/library/sqlite3.html) — working with SQLite databases using the standard library

## Libraries

- [SQLAlchemy documentation](https://docs.sqlalchemy.org/en/20/) — object-relational mapping (ORM) and Core for database access
- [NumPy documentation](https://numpy.org/doc/stable/) — multidimensional arrays and vectorized numerical computing
- [pandas documentation](https://pandas.pydata.org/docs/) — tabular data, filtering, grouping, and data analysis
- [Matplotlib documentation](https://matplotlib.org/stable/) — plotting graphs and charts, with a gallery of examples
- [Qt for Python documentation](https://doc.qt.io/qtforpython-6/) — widgets, signals and slots, and Model/View architecture in PySide6

## Tools

- [PyCharm documentation](https://www.jetbrains.com/help/pycharm/) — reference for the IDE, debugger, and test runner
- [uv documentation](https://docs.astral.sh/uv/) — managing Python versions, virtual environments, and dependencies
- [pytest documentation](https://docs.pytest.org/en/stable/) — writing unit tests, fixtures, and parametrization
- [mypy documentation](https://mypy.readthedocs.io/en/stable/) — static type checking using annotations
- [Ruff documentation](https://docs.astral.sh/ruff/) — a fast Python linter and code formatter
- [Python Packaging User Guide](https://packaging.python.org/en/latest/) — packaging projects, pyproject.toml, and publishing packages
- [PyInstaller Manual](https://pyinstaller.org/en/stable/) — building an application into an executable for distribution

## Tutorials and practice

- [Real Python — Object-Oriented Programming in Python](https://realpython.com/python3-object-oriented-programming/) — a detailed free tutorial on classes, objects, and inheritance
- [Python Tutor](https://pythontutor.com/) — step-by-step visualization of code execution, variables, and objects in memory
