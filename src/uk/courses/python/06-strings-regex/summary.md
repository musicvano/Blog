# Підсумки

## Висновки

Рядок `str` є незмінною послідовністю кодових точок, а `bytes` представляє закодовані байти. Методи рядків достатні для простого очищення й розділення; Unicode-нормалізація потрібна для порівняння канонічно еквівалентних записів. F-рядки одразу формують текст, а t-рядки зберігають сталі частини й значення для власного обробника. Регулярний вираз перевіряє структуру, проте семантичні обмеження дат, сум та інших даних перевіряються окремо.
