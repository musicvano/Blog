# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

## Порядок виконання роботи

1. Визначте типи даних, допустимі порожні стани та політику `null`.
2. Реалізуйте початковий, основний або підвищений рівень варіанта.
3. Розділіть консольний ввід, узагальнену модель і формування звіту.
4. Запустіть звичайні, граничні й неправильні приклади. Для обмежень типів додайте окремі файли, що не повинні компілюватися.
5. Поясніть кожне використання wildcard, межі або придушення попереджень. Не приховуйте попередження для цілого проєкту.
