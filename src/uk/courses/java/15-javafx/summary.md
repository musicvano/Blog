# Підсумки

## Висновки

JavaFX поєднує дерево вузлів, автоматичне компонування та події. Код створює поведінку, FXML описує структуру, CSS задає оформлення. Короткі обробники й окремі чисті обчислення спрощують перевірку та готують застосунок до MVC.

## Питання для самоперевірки

1. Чим Stage відрізняється від Scene?
2. Які дії не можна виконувати в init?
3. Чому setOnAction краще для звичайної кнопки?
4. Як VBox визначає розташування дітей?
5. Чому runLater не є фоновим потоком?
6. Коли `@FXML` поля контролера вже ініціалізовані?
7. Чому opens потрібний для приватних полів контролера?
8. Які перевірки треба повторити для зібраного образу?
