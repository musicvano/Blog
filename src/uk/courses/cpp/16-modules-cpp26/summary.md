# Підсумки

## Висновки

Поділ на файли та бібліотеки допомагає зробити межі відповідальності явними.
Заголовок описує інтерфейс для текстового включення; модуль надає керований
експорт і залежності імпорту. Обидва підходи потребують коректного
компонування й узгоджених параметрів. Автоматизований опис збирання
та тести роблять проєкт відтворюваним, а перевірка конкретних можливостей
дозволяє використовувати сучасний C++ без припущення про повну підтримку стандарту.

6. Чому не варто відкривати весь простір `std` у публічному заголовку?
7. Які артефакти потрібні для використання статичної бібліотеки?
