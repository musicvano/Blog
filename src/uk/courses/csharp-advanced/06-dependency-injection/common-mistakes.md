# Типові помилки

## Типові помилки

Найчастіші помилки під час використання DI, конфігурації та журналу зібрано в табл. 6.4.

Таблиця 6.4. Типові помилки впровадження залежностей, конфігурації та журналювання {.caption}

| **Проблема** | **Причина** | **Виправлення** |
| --- | --- | --- |
| `Unable to resolve service for type …` | залежність не зареєстровано або зареєстровано інший тип (клас замість інтерфейсу) | додати `Add…<IService, Impl>()`; `ValidateOnBuild` |
| `Cannot consume scoped service … from singleton` | Scoped-сервіс у конструкторі Singleton | узгодити часи життя або `IServiceScopeFactory` |
| значення з `appsettings.json` не читається | файл не скопійовано у вихідну папку, опечатка в ключі | `CopyToOutputDirectory`; шаблон параметрів |
| налаштування *Development* не діють після запуску `.exe` | `launchSettings.json` читають лише VS і `dotnet run` | задати `DOTNET_ENVIRONMENT` |
| пароль потрапив у репозиторій | секрет записано в `appsettings.json` | секрети користувача, змінні середовища; змінити пароль |
| записи в журналі без полів, повільна робота | інтерполяція `$"…"` замість шаблону | шаблон `{Name}` або `[LoggerMessage]` |
