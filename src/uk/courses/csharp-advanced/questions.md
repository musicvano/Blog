# Контрольні питання

Питання для самоперевірки та підготовки до іспиту, згруповані за темами курсу.

## Тема 1. Керування версіями Git

1. Що таке система керування версіями? Поясніть поняття репозиторію, коміту та індексу (staging area) у Git.
2. Опишіть основні команди Git для створення репозиторію, фіксації змін і перегляду історії (init, add, commit, status, log, diff).
3. Що таке гілки в Git? Порівняйте злиття (merge) та перебазування (rebase) гілок.
4. Як виникають конфлікти злиття і як їх розв’язувати, зокрема засобами Visual Studio 2026?
5. Поясніть роботу з віддаленими репозиторіями: clone, fetch, pull, push. Що таке запит на злиття (pull request) у GitHub?
6. Для чого призначений файл .gitignore? Які файли проєкту .NET не слід додавати до репозиторію?
