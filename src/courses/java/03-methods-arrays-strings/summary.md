# Summary

## Conclusions

Methods separate a contract from its implementation, arrays group data of the same type, and string APIs let you explicitly choose literal, Unicode, or pattern-based processing. Correctness depends on boundaries, empty sets, copying, and indexing units.

## Self-check questions

1. What is copied when an array is passed?
2. Can a method be overloaded by return type alone?
3. How does varargs behave without arguments?
4. What two conditions does recursion require?
5. How does an empty array differ from null?
6. What precondition does binarySearch have?
7. Why are two strings not compared using reference equality?
8. How does codePoints differ from chars?
9. When is StringBuilder needed?
10. Why does formatted not replace HTML escaping?
