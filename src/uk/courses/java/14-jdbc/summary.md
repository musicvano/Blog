# Підсумки

## Висновки

JDBC дає явний контроль ресурсів, SQL і транзакцій. Параметризовані запити відділяють дані від синтаксису, DAO – збереження від UI, а коротка транзакція захищає складену предметну дію. Наступні теми використають ці контракти у JavaFX, не переносячи SQL у обробник кнопки.
