# Підсумки

## Висновки

C++ дозволяє створювати нативні програми й використовувати різні способи
організації коду. Редакція стандарту, версія компілятора та налаштування
проєкту є різними характеристиками. Для прикладів теми потрібні актуальні
MSVC, стандартна бібліотека з `std::println`, режим `/std:c++latest`
і UTF-8. Шлях із заголовком `<print>` працює як у проєкті Visual Studio,
так і в простій команді `cl`; шлях `import std;` потребує підготовки модуля.

Препроцесування, компіляція та компонування перетворюють початковий текст
на виконуваний файл. Успішне збирання перевіряє лише частину коректності:
результат потрібно зіставити з очікуваним. Git зберігає зрозумілі кроки
розвитку програми, а `.gitignore` відділяє початкові матеріали від результатів
збирання. Публікація на GitHub доповнює локальну історію, але не замінює її.

## Питання для самоперевірки

1. Які задачі мотивують використання C++ та які обов’язки має розробник?
2. Чим стандарт C++ відрізняється від MSVC і Visual Studio?
3. Чому `/std:c++latest` не гарантує повної підтримки C++26?
4. До якого стандарту належать `std::println` і модуль `std`?
5. Що називають одиницею трансляції і навіщо потрібен компонувальник?
6. Чим файли `.cpp`, `.obj`, `.exe` і `.vcxproj` відрізняються за призначенням?
7. Яке навантаження Installer потрібне для консольного проєкту C++?
8. Чому властивості слід перевіряти для всіх конфігурацій?
9. Що означають `int`, `main`, `std::` і `return 0` у першій програмі?
10. Чим `#include <print>` відрізняється від `import std;` при збиранні?
11. Як `{:<28}` і `{:.2f}` впливають на виведення?
12. Чим помилка компіляції відрізняється від помилки компонування й логічної помилки?
13. Навіщо Developer PowerShell і що показує `$LASTEXITCODE`?
14. Чим збереження файла, `git add`, `git commit` та `git push` відрізняються?
15. Які файли проєкту потрібно зберігати в Git і для чого `.gitignore`?

3. Чим відрізняється режим `/std:c++latest` від повної підтримки стандарту?
4. Що позначають ширина, вирівнювання та `.2f` у рядку формату?
5. Чому зміна початкового коду без повторного збирання не змінює `.exe`?
6. Чим відрізняються Debug і Release та чому їхнє текстове виведення може бути однаковим?
7. Для чого використовується `/utf-8` і що ще впливає на вигляд консолі?
8. Чим відрізняються робочий каталог, індекс і локальний коміт Git?
9. Які файли проєкту потрібно зберігати в Git, а які ігнорувати?
10. Звідки `git restore -- main.cpp` бере вміст і що варто перевірити перед відновленням файла?
