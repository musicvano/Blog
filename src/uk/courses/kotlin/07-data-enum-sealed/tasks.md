# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Подайте UML класів; для станів також покажіть дозволені переходи. Використовуйте entries та вичерпний when, якщо обробляєте весь enum або sealed-тип. Усі навчальні тарифи й сумісності задаються умовою. Для високого рівня підтримайте `--help`, іменовані аргументи, повторюваний `--item` з описом формату, клавіатуру без аргументів, stderr і код 2 для помилок, код 0 для успіху. Звіт має вирівняні рядки та підсумки. Не викликайте зовнішні платіжні, медичні, поштові чи інші сервіси для локальних моделей.

1. Визначте, де потрібні значення, константи й альтернативні стани.
2. Намалюйте UML, а для sealed-моделі – переходи й дані станів.

7. Подайте код, UML, README та щонайменше п’ять перевірок.
8. На захисті додайте новий варіант sealed-типу та покажіть, які місця компілятор просить доповнити.
