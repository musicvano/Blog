# Корисні посилання

## Документація

- [Python documentation](https://docs.python.org/3/) — офіційна документація мови та стандартної бібліотеки
- [The Python Tutorial](https://docs.python.org/3/tutorial/) — офіційний посібник з основ мови від синтаксису до класів
- [Python Data Model](https://docs.python.org/3/reference/datamodel.html) — спеціальні методи, протоколи та поведінка об’єктів Python
- [Regular Expression HOWTO](https://docs.python.org/3/howto/regex.html) — вступ до регулярних виразів і модуля re
- [typing — Support for type hints](https://docs.python.org/3/library/typing.html) — анотації типів, узагальнення та протоколи
- [sqlite3 — DB-API 2.0 interface for SQLite databases](https://docs.python.org/3/library/sqlite3.html) — робота з базами даних SQLite засобами стандартної бібліотеки

## Бібліотеки

- [SQLAlchemy documentation](https://docs.sqlalchemy.org/en/20/) — об’єктно-реляційне відображення (ORM) і Core для роботи з базами даних
- [NumPy documentation](https://numpy.org/doc/stable/) — багатовимірні масиви та векторизовані числові обчислення
- [pandas documentation](https://pandas.pydata.org/docs/) — табличні дані, фільтрація, групування та аналіз даних
- [Matplotlib documentation](https://matplotlib.org/stable/) — побудова графіків і діаграм з галереєю прикладів
- [Qt for Python documentation](https://doc.qt.io/qtforpython-6/) — віджети, сигнали й слоти та архітектура Model/View у PySide6

## Інструменти

- [PyCharm documentation](https://www.jetbrains.com/help/pycharm/) — довідка середовища розробки, налагоджувача та запуску тестів
- [uv documentation](https://docs.astral.sh/uv/) — керування версіями Python, віртуальними середовищами та залежностями
- [pytest documentation](https://docs.pytest.org/en/stable/) — написання модульних тестів, фікстури та параметризація
- [mypy documentation](https://mypy.readthedocs.io/en/stable/) — статична перевірка типів за анотаціями
- [Ruff documentation](https://docs.astral.sh/ruff/) — швидкий лінтер і форматувальник коду Python
- [Python Packaging User Guide](https://packaging.python.org/en/latest/) — пакування проєктів, pyproject.toml і публікація пакетів
- [PyInstaller Manual](https://pyinstaller.org/en/stable/) — збирання застосунку у виконуваний файл для розповсюдження

## Навчальні посібники та практика

- [Real Python — Object-Oriented Programming in Python](https://realpython.com/python3-object-oriented-programming/) — докладний безкоштовний посібник з класів, об’єктів та успадкування
- [Python Tutor](https://pythontutor.com/) — покрокова візуалізація виконання коду, змінних і об’єктів у пам’яті
