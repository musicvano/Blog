# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Використайте Kotlin/JVM на JDK 27. Відокремте читання, обчислення й форматування; визначте алфавіт, межі чисел, поведінку порожнього тексту та неправильного формату. Не використовуйте реальні приватні номери чи облікові дані в прикладах.
