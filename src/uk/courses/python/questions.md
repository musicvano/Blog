# Контрольні питання

Питання для самоперевірки та підготовки до іспиту, згруповані за темами курсу.

## Тема 1. Python, PyCharm і Git

1. Що таке мова Python? Поясніть роботу інтерпретатора CPython: байт-код, віртуальна машина, динамічна типізація.
2. Як створити та запустити проєкт Python у JetBrains PyCharm? Як налаштувати інтерпретатор проєкту?
3. Що таке віртуальні середовища? Як їх створювати та активувати (venv)?
4. Як встановлювати пакети за допомогою pip та uv? Що таке PyPI і файл requirements.txt?
5. Що таке система керування версіями Git? Поясніть поняття репозиторію, коміту, гілки та основні команди Git.
6. Як працювати з репозиторієм Git у PyCharm? Які файли проєкту Python слід додавати до .gitignore?

## Тема 2. Типи, операції, керування

8. Порівняйте змінні (mutable) та незмінні (immutable) типи даних. Наведіть приклади.
9. Які операції підтримує мова Python? Поясніть цілочисельне ділення, піднесення до степеня та операцію присвоєння у виразі :=.
10. Як виконувати консольне введення за допомогою input та виведення за допомогою print? Як перетворювати типи даних?
11. Поясніть умовний оператор if-elif-else, цикли for і while та функцію range.
