# Корисні посилання

## Паралельне програмування в .NET

- [Parallel programming in .NET](https://learn.microsoft.com/en-us/dotnet/standard/parallel-programming/) — офіційний посібник з TPL, PLINQ і потокобезпечних колекцій
- [Managed threading](https://learn.microsoft.com/en-us/dotnet/standard/threading/) — потоки, пул потоків і примітиви синхронізації в .NET
- [System.Threading.Channels](https://learn.microsoft.com/en-us/dotnet/core/extensions/channels) — канали для патерну «виробник–споживач» з прикладами
- [Asynchronous programming with async and await](https://learn.microsoft.com/en-us/dotnet/csharp/asynchronous-programming/) — модель асинхронного програмування на основі задач у C#
- [SIMD-accelerated types in .NET](https://learn.microsoft.com/en-us/dotnet/standard/simd) — векторні типи та апаратне прискорення обчислень у .NET

## Високопродуктивні обчислення: OpenMP, CUDA, MPI

- [cppreference.com — Concurrency support library](https://en.cppreference.com/w/cpp/thread) — довідник потоків, м’ютексів, атомарних операцій і майбутніх значень C++
- [OpenMP Specifications](https://www.openmp.org/specifications/) — офіційні специфікації та довідкові картки OpenMP
- [CUDA Programming Guide](https://docs.nvidia.com/cuda/cuda-programming-guide/) — офіційний посібник з програмування графічних процесорів NVIDIA
- [ILGPU Documentation](https://ilgpu.net/docs/) — обчислення на графічних процесорах мовою C# з бібліотекою ILGPU
- [Open MPI Documentation](https://docs.open-mpi.org/en/main/) — встановлення, запуск і довідник функцій Open MPI
- [Slurm Workload Manager Documentation](https://slurm.schedmd.com/documentation.html) — налаштування кластера та запуск завдань через планувальник Slurm

## Розподілені системи та хмара

- [gRPC Documentation](https://grpc.io/docs/) — концепції, посібники та приклади віддаленого виклику процедур gRPC
- [RabbitMQ Documentation](https://www.rabbitmq.com/docs) — черги, обмінники та надійна доставка повідомлень у RabbitMQ
- [Microsoft Orleans documentation](https://learn.microsoft.com/en-us/dotnet/orleans/) — модель віртуальних акторів і розподілені застосунки на .NET
- [Docker Docs](https://docs.docker.com/get-started/) — основи контейнеризації, образи та Docker Compose
- [Kubernetes Documentation](https://kubernetes.io/docs/home/) — концепції, посібники та довідник оркестрації контейнерів Kubernetes
- [Aspire Documentation](https://aspire.dev/docs/) — оркестрація, телеметрія та розгортання розподілених застосунків .NET

## Теорія та архітектура

- [Introduction to Parallel Computing Tutorial (LLNL)](https://hpc.llnl.gov/documentation/tutorials/introduction-parallel-computing-tutorial) — архітектури, моделі паралелізму та проєктування паралельних програм
- [The Art of HPC (V. Eijkhout)](https://theartofhpc.com/) — безкоштовні підручники з HPC, паралельних алгоритмів, MPI та OpenMP
- [Microservice Architecture Patterns](https://microservices.io/patterns/) — каталог патернів мікросервісів — API-шлюз, сага, Outbox
