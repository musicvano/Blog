# Корисні посилання

## Документація .NET

- [Regular expressions in .NET](https://learn.microsoft.com/en-us/dotnet/standard/base-types/regular-expressions) — синтаксис регулярних виразів і клас Regex з прикладами
- [Windows Forms documentation](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/) — елементи керування, події та графіка в застосунках Windows Forms
- [Asynchronous programming with async and await](https://learn.microsoft.com/en-us/dotnet/csharp/asynchronous-programming/) — асинхронна модель на основі задач і ключові слова async/await
- [Dependency injection in .NET](https://learn.microsoft.com/en-us/dotnet/core/extensions/dependency-injection/overview) — контейнер залежностей, конфігурація та журналювання в Microsoft.Extensions
- [Windows Presentation Foundation documentation](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/) — XAML, прив’язка даних, стилі, шаблони та анімація у WPF
- [.NET Multi-platform App UI documentation](https://learn.microsoft.com/en-us/dotnet/maui/) — кросплатформні застосунки, навігація Shell і сервіси пристрою
- [Artificial intelligence in .NET](https://learn.microsoft.com/en-us/dotnet/ai/) — Microsoft.Extensions.AI, чат-клієнти та інтеграція мовних моделей

## Бази даних і вебсервіси

- [PostgreSQL Documentation](https://www.postgresql.org/docs/current/) — мова SQL, типи даних і можливості СКБД PostgreSQL
- [Npgsql Documentation](https://www.npgsql.org/doc/) — провайдер ADO.NET та EF Core для PostgreSQL
- [Entity Framework Core documentation](https://learn.microsoft.com/en-us/ef/core/) — моделі, міграції, запити LINQ і збереження даних
- [Sockets in .NET](https://learn.microsoft.com/en-us/dotnet/fundamentals/networking/sockets/socket-services) — клієнти й сервери TCP на класах Socket, TcpClient і TcpListener
- [Minimal APIs overview](https://learn.microsoft.com/en-us/aspnet/core/fundamentals/minimal-apis) — створення вебсервісів REST засобами ASP.NET Core Minimal API
- [ASP.NET Core SignalR](https://learn.microsoft.com/en-us/aspnet/core/signalr/introduction) — хаби, клієнти та обмін повідомленнями в реальному часі

## Інструменти та бібліотеки

- [Git Reference Manual](https://git-scm.com/docs) — офіційний довідник команд системи керування версіями Git
- [Learn Git Branching](https://learngitbranching.js.org/) — інтерактивні вправи з гілками, злиттям і перебазуванням у Git
- [Visual Studio documentation](https://learn.microsoft.com/en-us/visualstudio/windows/) — робота в середовищі розробки, налагодження та профілювання
- [MVVM Toolkit](https://learn.microsoft.com/en-us/dotnet/communitytoolkit/mvvm/) — ObservableObject, команди та генератори коду для патерну MVVM
- [regex101](https://regex101.com/) — онлайн-перевірка регулярних виразів з підтримкою діалекту .NET

## Спільнота, блоги та відео

- [.NET Blog](https://devblogs.microsoft.com/dotnet/) — новини платформи, огляди нових версій і технічні статті
- [.NET YouTube channel](https://www.youtube.com/@dotnet) — відеоуроки, доповіді .NET Conf і трансляції від Microsoft
