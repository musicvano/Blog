# Корисні посилання

## Документація

- [Kotlin documentation](https://kotlinlang.org/docs/home.html) — офіційна документація мови з прикладами та довідником API
- [Kotlin Standard Library API reference](https://kotlinlang.org/api/core/kotlin-stdlib/) — довідник класів і функцій стандартної бібліотеки Kotlin
- [Kotlin coding conventions](https://kotlinlang.org/docs/coding-conventions.html) — офіційні правила іменування, форматування та ідіоматичного стилю коду
- [Collections overview](https://kotlinlang.org/docs/collections-overview.html) — списки, множини, словники та операції над колекціями
- [Coroutines guide](https://kotlinlang.org/docs/coroutines-guide.html) — посібник з корутин, скоупів, контексту та скасування
- [Asynchronous Flow](https://kotlinlang.org/docs/flow.html) — асинхронні потоки даних Flow, оператори та обробка винятків
- [Kotlin serialization](https://kotlinlang.org/docs/serialization.html) — серіалізація об’єктів у JSON за допомогою kotlinx.serialization
- [Test code using JUnit in JVM](https://kotlinlang.org/docs/jvm-test-using-junit.html) — налаштування та написання модульних тестів з kotlin.test і JUnit

## Навчальні посібники та практика

- [Kotlin tour](https://kotlinlang.org/docs/kotlin-tour-welcome.html) — покроковий вступ до основ мови з інтерактивними вправами
- [Kotlin Koans](https://play.kotlinlang.org/koans/overview) — серія коротких задач для тренування синтаксису просто в браузері
- [Kotlin Playground](https://play.kotlinlang.org/) — онлайн-редактор для запуску та поширення коду Kotlin без встановлення
- [Baeldung Kotlin tutorials](https://www.baeldung.com/kotlin/) — практичні статті про мову, корутини, тестування та бібліотеки

## Інструменти та бібліотеки

- [IntelliJ IDEA documentation](https://www.jetbrains.com/help/idea/) — довідка середовища розробки, налагоджувача та інструментів рефакторингу
- [Gradle User Manual](https://docs.gradle.org/current/userguide/userguide.html) — збирання проєктів, залежності та скрипти на Kotlin DSL
- [Git Reference Manual](https://git-scm.com/docs) — довідник команд системи контролю версій Git
- [Exposed documentation](https://www.jetbrains.com/help/exposed/home.html) — робота з реляційними базами даних через DSL і DAO
- [Compose Multiplatform](https://kotlinlang.org/docs/multiplatform/compose-multiplatform.html) — створення декларативного графічного інтерфейсу для настільних застосунків
- [Navigation in Compose Multiplatform](https://kotlinlang.org/docs/multiplatform/compose-navigation-routing.html) — навігація між екранами застосунку в Compose Multiplatform

## Спільнота, блоги та відео

- [The Kotlin Blog](https://blog.jetbrains.com/kotlin/) — офіційні новини про релізи мови, інструментів і бібліотек
- [Kotlin by JetBrains on YouTube](https://www.youtube.com/@Kotlin) — відеоуроки, доповіді KotlinConf та огляди нових можливостей
