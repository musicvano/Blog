# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Використайте Kotlin/JVM, JDK 27, явні типи функціонального API й визначений порядок результатів. Не приховуйте втрату дублікатів у `associateBy` і не запускайте нескінченну послідовність кінцевою операцією без обмеження.
