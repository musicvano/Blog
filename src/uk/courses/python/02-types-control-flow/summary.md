# Підсумки

## Висновки

Ім’я в Python посилається на об’єкт, який має власний тип. Числові обчислення потребують правильного вибору типу, одиниць і правила округлення. Введення спочатку є текстом, тому перетворення й перевірка мають бути явними. Розгалуження визначають шлях виконання, а цикли дозволяють застосувати алгоритм до серії значень без дублювання коду.

## Питання для самоперевірки

1. Що змінюється після повторного присвоєння імені?
2. Чим відрізняються `==` та `is`?
3. Які обмеження має точність `int` і `float`?
4. Чому `0.1 + 0.2 == 0.3` дає хибний результат?
5. Коли варто використовувати цілі копійки або Decimal?
6. Чому `bool("False")` є істинним?
7. Чим `//` для від’ємних чисел відрізняється від відкидання дробу?
8. Як коротке обчислення захищає від ділення на нуль?
9. Чим перевірка формату відрізняється від перевірки діапазону?
10. Коли кілька `if` не можна замінити ланцюжком `elif`?
11. Що означає окреме ім’я після `case`?
12. Які числа задає `range(8, 1, -3)`?
13. Коли виконується `else` циклу?
14. Чому мінімум серії не завжди можна починати з нуля?
15. Які контрольні дані потрібні для перевірки всіх гілок?
