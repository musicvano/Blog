# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Для всіх рівнів подайте UML класів із видимістю полів, конструкторами й методами. Модель не читає консоль; інтерфейс перетворює рядки та обробляє відмови.

## Варіанти

### Варіант 1. Банківська картка {#v1}

**1. Початковий рівень.** Створити консольну програму Java: ввести номер із 16 цифр, залишок 0..1000000 копійок і суму списання; клас Card приховує залишок, списує тільки додатну доступну суму й показує маску номера та новий залишок. Подати UML класів; використати приватні поля, перевірений конструктор, методи доступу та `toString()`.

**2. Базовий рівень.** Створити консольну програму Java: ввести номер із 16 цифр, залишок 0..1000000 копійок і суму списання; клас Card приховує залишок, списує тільки додатну доступну суму й показує маску номера та новий залишок. Подати UML класів; використати приватні поля, перевірений конструктор, методи доступу та `toString()`. Обробити масив від 1 до 20 наборів із клавіатури, перевірити кожне поле до зміни стану; вивести рядок результату для кожного набору й кількість прийнятих та відхилених наборів.

**3. Високий рівень.** Створити консольну програму Java: ввести номер із 16 цифр, залишок 0..1000000 копійок і суму списання; клас Card приховує залишок, списує тільки додатну доступну суму й показує маску номера та новий залишок. Подати UML класів; використати приватні поля, перевірений конструктор, методи доступу та `toString()`. Вивести вирівняну таблицю результатів і підсумкові кількості; додати щонайменше п’ять перевірок: звичайну, граничну, неправильний формат, порушення інваріанта та відмову без зміни стану.

## Порядок виконання та захисту роботи

1. Запишіть поля, одиниці, межі та інваріанти.
2. Намалюйте UML й визначте публічні операції.
3. Реалізуйте конструктори та перевірки до зміни стану.
4. Перевірте два незалежні об’єкти, спільне посилання, успіх, межу й відмову без часткової зміни.
5. Відокремте пакети model/app та зберіть виконуваний JAR.
6. Подайте код, UML, README й щонайменше п’ять перевірок.
7. На захисті покажіть this, static і закриті поля в debugger.
