# Useful links

## Documentation

- [Dev.java](https://dev.java/learn/) — Oracle's official Java learning materials
- [Java SE Documentation](https://docs.oracle.com/en/java/javase/) — API reference, guides, and JDK tools for each version
- [Java Language and Virtual Machine Specifications](https://docs.oracle.com/javase/specs/) — formal descriptions of Java syntax and semantics
- [JDK Enhancement Proposals](https://openjdk.org/jeps/0) — descriptions of new language features, including records and pattern matching

## Tools and libraries

- [IntelliJ IDEA documentation](https://www.jetbrains.com/help/idea/) — working in the development environment, debugging, and refactoring code
- [Git Reference Manual](https://git-scm.com/docs) — the official command reference for the Git version control system
- [Maven Documentation](https://maven.apache.org/guides/) — guides to building projects and managing dependencies in Maven
- [Gradle User Manual](https://docs.gradle.org/current/userguide/userguide.html) — configuring builds, dependencies, and tasks in Gradle
- [JUnit User Guide](https://docs.junit.org/current/user-guide/) — writing and running unit tests in JUnit
- [OpenJFX Documentation](https://openjfx.io/openjfx-docs/) — installing JavaFX and configuring projects in development environments
- [Scene Builder](https://gluonhq.com/products/scene-builder/) — a visual FXML editor for designing JavaFX interfaces

## Databases

- [JDBC API (java.sql)](https://docs.oracle.com/en/java/javase/27/docs/api/java.sql/java/sql/package-summary.html) — the Connection, PreparedStatement, and ResultSet interfaces for database access
- [PostgreSQL JDBC Driver](https://jdbc.postgresql.org/documentation/) — connecting to PostgreSQL from Java and configuring driver parameters
- [PostgreSQL Documentation](https://www.postgresql.org/docs/current/) — SQL, data types, and features of the PostgreSQL database management system

## Tutorials and practice

- [Baeldung Java Tutorial](https://www.baeldung.com/java-tutorial) — articles with examples on the language, collections, the Stream API, and testing
- [Jenkov Java Tutorials](https://jenkov.com/tutorials/java/index.html) — sequential tutorials on Java, collections, NIO, and JDBC
- [Java Programming MOOC](https://java-programming.mooc.fi/) — a free University of Helsinki course with exercises from fundamentals to OOP
- [Learn Git Branching](https://learngitbranching.js.org/) — interactive exercises on branches, merging, and rebasing in Git

## Community, blogs, and videos

- [Inside.java](https://inside.java/) — news, articles, and podcasts from Java developers at Oracle
- [Java YouTube channel](https://www.youtube.com/@java) — overviews of new Java releases, talks, and video tutorials
