# Корисні посилання

## Документація та стандарт

- [cppreference.com](https://en.cppreference.com/w/cpp) — довідник мови C++ і стандартної бібліотеки з прикладами
- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) — правила сучасного C++ від Б. Страуструпа та Г. Саттера
- [Microsoft C/C++ documentation](https://learn.microsoft.com/en-us/cpp/) — документація MSVC, бібліотек і збирання проєктів у Visual Studio
- [C++ Language Reference (Microsoft Learn)](https://learn.microsoft.com/en-us/cpp/cpp/cpp-language-reference) — опис синтаксису та семантики мови C++ з прикладами
- [Microsoft C/C++ language conformance](https://learn.microsoft.com/en-us/cpp/overview/visual-cpp-language-conformance) — які можливості стандартів C++ підтримує компілятор MSVC
- [C++ Standard Draft](https://eel.is/c++draft/) — актуальна чернетка стандарту C++ із навігацією за розділами

## Навчальні ресурси та практика

- [LearnCpp](https://www.learncpp.com) — покроковий безкоштовний підручник з C++ від основ до ООП
- [Welcome back to C++ (Modern C++)](https://learn.microsoft.com/en-us/cpp/cpp/welcome-back-to-cpp-modern-cpp) — огляд ідіом сучасного C++: RAII, розумні вказівники, контейнери
- [hacking C++](https://hackingcpp.com) — ілюстровані шпаргалки та уроки зі стандартної бібліотеки C++
- [Exercism C++ Track](https://exercism.org/tracks/cpp) — задачі з автоматичною перевіркою та рецензіями менторів

## Середовище та інструменти

- [Visual Studio debugger feature tour](https://learn.microsoft.com/en-us/visualstudio/debugger/debugger-feature-tour) — точки зупинки, покрокове виконання та перегляд змінних
- [CMake projects in Visual Studio](https://learn.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio) — створення, збирання та налагодження CMake-проєктів у Visual Studio
- [CMake Tutorial](https://cmake.org/cmake/help/latest/guide/tutorial/index.html) — офіційний покроковий посібник зі збирання проєктів за допомогою CMake
- [Git Reference Manual](https://git-scm.com/docs) — офіційний довідник команд системи керування версіями Git
- [Compiler Explorer](https://godbolt.org) — онлайн-компіляція коду різними компіляторами з переглядом асемблера
- [C++ Insights](https://cppinsights.io) — показує, як компілятор розгортає шаблони, лямбди та цикли

## Спільнота, блоги та відео

- [Standard C++ Foundation](https://isocpp.org) — новини стандарту, статті та відповіді на поширені питання
- [C++ Stories](https://www.cppstories.com) — блог Б. Філіпека про нові можливості стандартів C++
- [CppCon](https://www.youtube.com/@CppCon) — записи доповідей найбільшої конференції з C++
- [C++ Weekly With Jason Turner](https://www.youtube.com/@cppweekly) — короткі щотижневі відео про прийоми та можливості C++
