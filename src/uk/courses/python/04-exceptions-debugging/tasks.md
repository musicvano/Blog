# Завдання

Відповідно до номера свого варіанта виконайте завдання обраного рівня складності.

Кожне формулювання повністю визначає окрему програму. Використовуйте Python 3.14, анотації параметрів і результатів функцій та стандартну бібліотеку. Для кількох типів без зв’язування об’єкта застосовуйте `except ValueError, TypeError:`; із `as` використовуйте дужки. Усі тарифи, курси, ліміти та медичні параметри нижче – вигадані константи для перевірки програм. Задача дозування є арифметичним симулятором без реальних назв препаратів. Грошові суми зберігайте цілими одиницями або копійками відповідно до умови. Для дійсних даних відхиляйте NaN і нескінченності. Не використовуйте `eval` для калькулятора; обирайте дозволені операції через розгалуження.
