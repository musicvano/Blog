# Підсумки

## Висновки

CPython виконує байт-код, PyCharm організовує розробку, середовище відокремлює залежності, а Git зберігає історію. Для запуску потрібні код і правильно вибраний інтерпретатор; для передавання проєкту – також опис залежностей та інструкція.

5. Де вводять команди оболонки, а де – вирази Python?

7. Як прочитати traceback та знайти помилковий рядок?
8. Чим відрізняються *Run*, *Python Console* і *Terminal*?
9. Як перевірити інтерпретатор проєкту?
10. Чи обов’язково активувати віртуальне середовище?
