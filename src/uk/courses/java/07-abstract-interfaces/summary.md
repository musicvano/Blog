# Підсумки

## Висновки

Абстрактний клас поєднує спільний стан із точками розширення, інтерфейс задає роль, а вкладені класи локалізують допоміжні реалізації. Надійність визначає чіткий контракт: порядок порівняння, завершення ітерації та незалежність готового результату.

## Питання для самоперевірки

1. Навіщо абстрактному класу конструктор?
2. Які члени інтерфейсу неявно публічні?
3. Чим default відрізняється від static?
4. Як розв’язати конфлікт двох default методів?
5. Коли потрібний абстрактний клас замість інтерфейсу?
6. Чому compareTo не слід реалізовувати відніманням?
7. Що має зробити next після завершення обходу?
8. Яке посилання має inner, але не має static nested?
9. Що означає effectively final?
10. Як інтерфейс дозволяє замінити стратегію?
