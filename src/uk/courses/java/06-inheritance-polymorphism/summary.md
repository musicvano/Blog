# Підсумки

## Висновки

Наслідування визначає підтип і спільний контракт, поліморфізм обирає екземплярну реалізацію за об’єктом, а композиція приховує помічників за вузьким API. Коректна ієрархія потребує не лише `extends`, а й узгоджених інваріантів, конструкторів і правил рівності.

6. Чим приховування static відрізняється від перевизначення?
7. Який тип визначає реалізацію екземплярного методу?
8. Чому instanceof безпечніший за неперевірене приведення?
